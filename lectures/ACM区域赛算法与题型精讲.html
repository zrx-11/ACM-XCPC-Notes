相同整数满足 x xor x=0。若恰有两个数出现奇数次，总异或值 z 就是这两个数的异或； 选取 z 的任一置位分组，两数必落在不同组中，再分别异或即可。位图则以一位记录一个有限 状态，适用于可控值域。

1.3从数据范围选择算法

总成本由状态数、每个状态的转移数及单次运算代价共同决定。n≤20 只是集合状态的规 模提示；若再加入末尾位置或枚举下一项，时间与内存都需相应增加。扩展图、数位余数与自 动机状态也应计入总规模。 主要规模 首先考虑 需要额外检查 n 约 20 子集枚举与状压 2^n 的状态大小与转移数 n 约 40 折半枚举 合并方式与内存 n 约几千 平方或部分立方 DP 时限与常数 n 达十万以上 排序 扫描 对数结构 总数据量与哈希风险 表中的范围仅供初步选型。最终仍需结合时限、语言与常数估算；多组输入按 Σn、Σm 计 算总规模，高精度运算还需考虑整数位数。

1.4容器排序与实现规范

vector 用于顺序存储，queue 用于 FIFO，priority_queue 用于最值候选，set 或 multiset 用于 前后继与任意删除。unordered_map 的期望常数复杂度依赖散列；对抗输入可采用随机盐散列 或改用排序与离散化。比较器必须满足严格弱序，不能写成 a≤b，也不要通过可能溢出的减法 比较大小。 固定下标约定：原数组与 STL 通常从 0 开始，Fenwick 从 1 开始；闭区间 [l,r] 与半开区间 [l,r) 不混用。多组数据的容器放在 solve 内，全局计数、队列、Trie 节点与访问标记应清空实 际使用范围。 乘法与坐标差都应在运算前提升类型。负余数先规范化，整数除法按需要采用 floor 或 ceil。INF 既要大于合法答案，也要为后续加法保留余量。

1.5整数除法与判定边界

C++ 的整数除法向零截断，例如 −5/2 得到 −2，而数学向下取整是 −3。二分判定、等差 操作起点与整点不等式经常需要精确的 floor 或 ceil。先计算商与余数，再根据余数和除数的 符号调整，避免使用加上 b−1 的只适用于正数的写法。

C++17
i128 floor_div(ll a, ll b) {
    assert(b != 0);
    i128 q = i128(a) / b, r = i128(a) % b;
    if (r != 0 && ((r < 0) != (b < 0)))
        --q;
    return q;
}
i128 ceil_div(ll a, ll b) {
    assert(b != 0);
    i128 q = i128(a) / b, r = i128(a) % b;
    if (r != 0 && ((r < 0) == (b < 0)))
        ++q;
    return q;
}

先将 ll 输入提升为 i128 再相除，以覆盖最小值除以 −1 的结果。返回值缩回 ll 前应检查范 围；阈值比较优先整理为整数不等式，避免舍入改变边界。 验证判定时，重点检查分界附近的 x−1、x、x+1，以及重复值、负数和极值。判定逻辑需 先于二分验证。

2枚举分治与贪心

枚举明确候选范围，分治拆分子问题，贪心利用可证明的选择次序。三类方法的共同出发 点是完整描述解空间，再依据结构减少搜索；允许撤销旧选择时，可用堆维护当前最优集合。

2.1归并排序与逆序对

归并时，若当前右值小于当前左值，它也小于左半区尚未输出的全部元素，因此可一次计 入这些跨区逆序对。左右半区内部的逆序对递归统计，与跨区部分互不重叠。 图 2.1 归并时批量统计跨区逆序对

复杂度与接口时间 O(n log n)，额外空间 O(n)。

C++17
ll inversions(vector<ll> &a) {
    vector<ll> tmp(a.size());
    function<ll(int, int)> dfs = [&](int l, int r) -> ll {
        if (r - l <= 1)
            return 0;
        int m = (l + r) / 2;
        ll ans = dfs(l, m) + dfs(m, r);
        int i = l, j = m, k = l;
        while (i < m && j < r) {
            if (a[i] <= a[j])
                tmp[k++] = a[i++];
            else
                ans += m - i, tmp[k++] = a[j++];
        }
        while (i < m)
            tmp[k++] = a[i++];
        while (j < r)
            tmp[k++] = a[j++];
        copy(tmp.begin() + l, tmp.begin() + r, a.begin() + l);
        return ans;
    };
    return dfs(0, a.size());
}

实现要点本实现统计 a[i]>a[j] 的普通逆序对。对于 a[i]>2a[j]，应在两个有序半区上另做双指

针计数，再执行归并；倍乘前须提升类型。 归并还可累计跨区间的小和：当某个左值可贡献给一段右值时，一次乘入对应数量。排序 与选择工具的比较见 2.5 节。

2.2回溯位压缩与 N 皇后

回溯的核心是增量维护约束，并在离开分支时恢复状态。N 皇后按行选列，只需记列、左 斜线、右斜线的占用；位运算能一次枚举当前所有可选列，减少检查常数。

复杂度与接口搜索为指数级；位压缩减少每个状态的检查开销。

C++17
unsigned long long queens(int n) {
    assert(0 <= n && n < 32);
    unsigned int full = n ? (1U << n) - 1 : 0;
    function<unsigned long long(unsigned int, unsigned int, unsigned int)>
        dfs;
    dfs = [&](auto col, auto L, auto R) -> unsigned long long {
        if (col == full)
            return 1;
        auto ok = full & ~(col | L | R);
        unsigned long long ans = 0;
        while (ok) {
            auto p = ok & (0U - ok);
            ok -= p;
            ans += dfs(col | p, ((L | p) << 1) & full, (R | p) >> 1);
        }
        return ans;
    };
    return dfs(0, 0, 0);
}

实现要点本实现要求 n<32，且答案可由 unsigned long long 保存。全排列与子集枚举在计入输

出后分别为 O(n!·n)、O(2ⁿ·n)，应先核对规模。 剪枝必须给出必要条件：不可能完成的分支才可删除。任意选择顺序、对称性减半和只找 一个解各有不同计数语义，不可直接混用。 有重复元素的排列每层用集合去重，或排序后使用“相同值的前一个尚未使用时跳过”。 组合与子序列枚举、汉诺塔、递归逆序栈和栈排序都是典型应用。Master 公式只适用于相同规 模递归；T(n)=aT(n/b)+O(nᶜ) 若 log_b a>c，则为 O(n^(log_b a))；相等则为 O(n^c log n)；较小 则为 O(n^c)。额外 log 因子需单独判断。

vector<ll> subset_sums(const vector<ll> &a) {
    vector<ll> s{0};
    for (ll x : a) {
        int n = s.size();
        for (int i = 0; i < n; i++)
            s.push_back(s[i] + x);

    return s;

ll count_leq(const vector<ll> &a, ll W) {
    int m = a.size() / 2;
    auto L = subset_sums(vector<ll>(a.begin(), a.begin() + m));
    auto R = subset_sums(vector<ll>(a.begin() + m, a.end()));
    sort(R.begin(), R.end());
    ll ans = 0;
    for (ll x : L)
        ans += upper_bound(R.begin(), R.end(), W - x) - R.begin();
    return ans;
}

2.4区间调度与反悔堆

反悔贪心允许在处理更晚的约束时，撤销此前最不合适的选择。按截止时间排序后维护已 选任务总耗时，一旦超出当前截止时间就删去耗时最长任务，使留下的集合尽可能短。

复杂度与接口时间 O(n log n)，空间 O(n)。

C++17
int max_courses(vector<pair<ll, ll>> jobs) {
    // pair 为 duration, deadline。
    sort(jobs.begin(), jobs.end(),
         [](auto a, auto b) { return a.second < b.second; });
    priority_queue<ll> q;
    ll t = 0;
    for (auto [d, ddl] : jobs) {
        t += d;
        q.push(d);
        if (t > ddl)
            t -= q.top(), q.pop();
    }
    return q.size();
}
ll huffman_cost(vector<ll> a) {
    priority_queue<ll, vector<ll>, greater<ll>> q(a.begin(), a.end());
    ll ans = 0;
    while (q.size() > 1) {
        ll x = q.top();
        q.pop();
        ll y = q.top();
        q.pop();
        ans += x + y;
        q.push(x + y);
    }
    return ans;
}

实现要点区间端点能否相接决定 ≥ 或 >。课程模型要求时长为正且截止期是完成期限；不能

直接套到有依赖或额外收益的任务。 交换论证要说明删除最长任务不会减少未来可安排数量。利润、耗时和截止时间角色不 同；只有相同目标的可交换结构才支持同一堆策略。

2.5构造题与交换论证

构造题先从总量、奇偶、颜色容量、连通性或度数建立必要条件，再寻找保持这些条件的 局部操作。完整解法还需证明操作合法、过程终止，并覆盖全部可行输入。 贪心证明常用三种形式。交换论证把任意最优解改成符合当前选择的最优解；领先论证比 较处理任意前缀后的进度；不变量论证说明每次操作维持可延伸的最优状态。区间调度选最早 结束、Huffman 合并最小两项和反悔删最长任务，虽然都用排序或堆，证明对象各不相同。 排序工具应按任务选择：随机三路快排适合大量重复值，nth_element 适合平均线性的第 k 小选择，归并适合稳定排序与跨区贡献统计，基数排序适合固定长度整数键。

template <class F> optional<ll> first_true(ll lo, ll hi, F check) {

ll count_sum(const vector<ll> &a, ll k) {

void add_ap(vector<ll> &dd, int l, int r, ll s, ll d) {
    ll e = s + (r - l) * d;
    dd[l] += s;
    dd[l + 1] += d - s;
    dd[r + 1] -= e + d;
    dd[r + 2] += e;
}
vector<ll> restore_ap(vector<ll> dd, int n) {
    for (int k = 0; k < 2; k++)

3.5双指针与至多 k 类计数

当区间扩大使“种类不超过 k”只能从满足变成不满足，右端前进时左端也只需前进。固 定右端 r，合法左端形成连续后缀，因此合法区间数是 r−l+1。恰好 k 类可用 atMost(k) −atMost(k−1)。

复杂度与接口平均 O(n)，空间与窗口内不同元素数相关。

C++17
ll at_most(const vector<int> &a, int k) {
    if (k < 0)
        return 0;
    unordered_map<int, int> cnt;
    int l = 0, kinds = 0;
    ll ans = 0;
    for (int r = 0; r < (int)a.size(); r++) {
        if (++cnt[a[r]] == 1)
            ++kinds;
        while (kinds > k) {
            if (--cnt[a[l]] == 0) {
                cnt.erase(a[l]);
                --kinds;
            }
            ++l;
        }
        ans += r - l + 1;
    }
    return ans;
}

维护缺少的字符数，不能只维护不同字符数。 双指针的线性界来自每个端点最多移动 n 次。区间和约束只有在元素非负等条件下才有相 同单调性；负数数组应改用前缀状态或单调队列。 窗口还能维护最小覆盖串、无重复字符最长串与平衡串替换。每字符至少 k 次可枚举目标 字符种类数，使窗口重新获得单调约束。环形区间可复制一段数组；两端接雨水、救生艇和最 大容器则通过局部上界判断该移动哪一侧。供暖半径可排序后双指针或二分，重复数可用快慢 指针，最小缺失正数可用原地置换。它们共享移动与状态维护思想，单调性理由各不相同。

3.6可删除的中位数与绝对差代价

绝对差之和在中位数处最小。用两个有序多重集合，将较小的一半放 lo，较大的一半放 hi；保证 lo 大小等于 hi 或多一，并保存两边的元素和。这样代价可由中位数乘数量减元素和 得到。

复杂度与接口插入删除 O(log n)，查询代价 O(1)，空间 O(n)。

C++17
struct Median {
    multiset<ll> L, R;
    ll sl = 0, sr = 0;
    void balance() {
        while (L.size() > R.size() + 1) {
            auto it = prev(L.end());
            ll x = *it;
            L.erase(it);
            sl -= x;
            R.insert(x);
            sr += x;
        }
        while (L.size() < R.size()) {
            auto it = R.begin();
            ll x = *it;
            R.erase(it);
            sr -= x;
            L.insert(x);
            sl += x;
        }
    }
    void add(ll x) {
        if (L.empty() || x <= *L.rbegin())
            L.insert(x), sl += x;
        else
            R.insert(x), sr += x;
        balance();
    }
    void erase(ll x) {
        auto it = L.find(x);
        if (it != L.end())
            L.erase(it), sl -= x;
        else {
            it = R.find(x);
            assert(it != R.end());
            R.erase(it);
            sr -= x;
        }
        balance();
    }
    ll cost() const {
        if (L.empty())
            return 0;
        ll m = *L.rbegin();
        return m * (ll)L.size() - sl + sr - m * (ll)R.size();
    }
};

口的代价为 0。 只插入的中位数可用双堆维护；滑动窗口还需处理任意位置删除，可选择多重集合、延迟 删除或频次树状数组。

bool cards_check(const vector<ll> &a, const vector<ll> &b, ll x, int need) {
    int base = 0, end = 0, best = 0;
    for (int i = 0; i < (int)a.size(); i++) {
        base += a[i] >= x;
        int gain = (b[i] >= x) - (a[i] >= x);
        end = max(0, end + gain);

4.1单调栈与贡献边界

贡献法以每个位置作为区间最小值计数。找到它左侧与右侧最近的阻挡边界，左端可选数 乘右端可选数就是它的贡献次数。重复值必须由一侧严格、另一侧非严格来划分归属，否则同 一段会重复或遗漏。

复杂度与接口时间 O(n)，空间 O(n)。

C++17
i128 sum_min(const vector<ll> &a) {
    int n = a.size();
    vector<int> L(n), R(n), st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.back()] >= a[i])
            st.pop_back();
        L[i] = st.empty() ? -1 : st.back();
        st.push_back(i);
    }
    st.clear();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && a[st.back()] > a[i])
            st.pop_back();
        R[i] = st.empty() ? n : st.back();
        st.push_back(i);
    }
    i128 ans = 0;
    for (int i = 0; i < n; i++)
        ans += (i128)a[i] * (i - L[i]) * (R[i] - i);
    return ans;
}

int shortest_at_least(const vector<ll> &a, ll k) {
    int n = a.size(), ans = n + 1;
    vector<ll> s(n + 1);
    deque<int> q;
    for (int i = 0; i < n; i++)
        s[i + 1] = s[i] + a[i];
    for (int r = 0; r <= n; r++) {
        while (!q.empty() && s[r] - s[q.front()] >= k)
            ans = min(ans, r - q.front()), q.pop_front();

        q.push_back(r);

struct Fenwick {
    int n;
    vector<ll> bit;
    explicit Fenwick(int n) : n(n), bit(n + 1) {}
    void add(int i, ll v) {
        assert(1 <= i && i <= n);
        for (; i <= n; i += i & -i)
            bit[i] += v;
    }
    ll sum(int i) const {
        ll s = 0;
        for (; i > 0; i -= i & -i)
            s += bit[i];
        return s;
    }
    ll range(int l, int r) const { return sum(r) - sum(l - 1); }
    int kth(ll k) const {
        assert(k >= 1 && k <= sum(n));
        int x = 0, step = 1;
        while (step <= n / 2)
            step <<= 1;
        for (; step; step >>= 1)
            if (x + step <= n && bit[x + step] < k)
                k -= bit[x += step];
        return x + 1;
    }
};

4.4树状数组的区间修改与第 k 小查询

前缀和不是树状数组的唯一用途。对差分数组建树，可以把区间加拆成两个单点；若存储 非负频次，还能在树的隐式层级上直接寻找第 k 个元素。 设 d 为原数组差分。前 x 项和等于 Σ(i≤x)(x−i+1)d[i]，整理为 (x+1)Σd[i]−Σi·d[i]。因此维 护 d[i] 和 i·d[i] 两棵树即可。寻找第 k 个元素时，从最高二进制位开始试探前缀位置：若整块 频次仍小于 k，就跳过它并减去其贡献。

4.5单点修改与区间最大值

线段树通过区间二分把任意查询分解成 O(log n) 个节点区间。每个节点保存可合并的摘 要，最大值的合并是 max，区间和的合并是加法。节点摘要必须足够回答上层查询。

复杂度与接口初始化 O(n)，更新与查询 O(log n)，空间 O(n)。

C++17
struct SegMax {
    int n;
    vector<ll> t;
    explicit SegMax(const vector<ll> &a) : n(a.size()), t(2 * n, -INF) {
        for (int i = 0; i < n; i++)
            t[n + i] = a[i];
        for (int i = n - 1; i; i--)
            t[i] = max(t[i << 1], t[i << 1 | 1]);
    }
    void set(int p, ll v) {
        for (t[p += n] = v; p > 1; p >>= 1)
            t[p >> 1] = max(t[p], t[p ^ 1]);
    }
    ll query(int l, int r) const {
        ll ans = -INF;
        for (l += n, r += n; l < r; l >>= 1, r >>= 1) {
            if (l & 1)
                ans = max(ans, t[l++]);
            if (r & 1)
                ans = max(ans, t[--r]);
        }
        return ans;
    }
};

实现要点最大值的单位元应为负无穷，不能用 0 处理可能为负的数组。求和、计数、第 k 个

等操作需要更换合并规则和单位元。 最大子段和查询需同时保存区间总和、最大前缀和、最大后缀和与最大子段和。节点信息 应由合并公式反推，单独保存 sum 不足以完成这种查询。

struct LazySum {
    int n;
    vector<ll> s, z;
    explicit LazySum(const vector<ll> &a) : n(a.size()), s(4 * n), z(4 * n) {
        assert(n);
        build(1, 0, n, a);
    }
    void build(int u, int l, int r, const vector<ll> &a) {
        if (r - l == 1) {
            s[u] = a[l];
            return;
        }
        int m = (l + r) / 2;
        build(u * 2, l, m, a);
        build(u * 2 + 1, m, r, a);
        s[u] = s[u * 2] + s[u * 2 + 1];
    }
    void apply(int u, int len, ll v) {
        s[u] += len * v;
        z[u] += v;
    }
    void push(int u, int l, int r) {
        int m = (l + r) / 2;
        apply(u * 2, m - l, z[u]);
        apply(u * 2 + 1, r - m, z[u]);
        z[u] = 0;
    }
    void add(int ql, int qr, ll v, int u, int l, int r) {
        if (qr <= l || r <= ql)
            return;
        if (ql <= l && r <= qr) {
            apply(u, r - l, v);
            return;
        }
        push(u, l, r);
        int m = (l + r) / 2;
        add(ql, qr, v, u * 2, l, m);
        add(ql, qr, v, u * 2 + 1, m, r);
        s[u] = s[u * 2] + s[u * 2 + 1];
    }
    ll sum(int ql, int qr, int u, int l, int r) {
        if (qr <= l || r <= ql)
            return 0;
        if (ql <= l && r <= qr)
            return s[u];
        push(u, l, r);
        int m = (l + r) / 2;
        return sum(ql, qr, u * 2, l, m) + sum(ql, qr, u * 2 + 1, m, r);
    }
    void add(int l, int r, ll v) { add(l, r, v, 1, 0, n); }
    ll sum(int l, int r) { return sum(l, r, 1, 0, n); }
};

struct SparseMin {
    vector<int> lg;
    vector<vector<ll>> st;
    explicit SparseMin(const vector<ll> &a) : lg(a.size() + 1) {
        int n = a.size();
        assert(n);
        for (int i = 2; i <= n; i++)
            lg[i] = lg[i / 2] + 1;
        st.assign(lg[n] + 1, vector<ll>(n));
        st[0] = a;
        for (int k = 1; k <= lg[n]; k++)
            for (int i = 0; i + (1 << k) <= n; i++)
                st[k][i] = min(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);
    }
    ll query(int l, int r) const {
        int k = lg[r - l];
        return min(st[k][l], st[k][r - (1 << k)]);
    }
};

4.8离线查询与普通莫队

当所有询问提前给出，且区间答案可以用一次加入或删除快速更新时，可以改变询问次 序，复用相邻区间的状态。莫队并不要求答案可合并，它要求端点移动可维护。 把左端点按长度 B 分块，块内按右端点排序；相邻块交替使用升序和降序，减少右端点 来回扫描。维护当前闭区间 [L,R]，每一步只加或删一个位置。不同数个数的更新只关心该值 的频次是否跨过零。

正确性每次移动后，频次数组准确描述当前区间。一个左端块内右端累计移动 O(n)，共有

O(n/B) 块；左端移动合计 O(qB)。取 B≈n/√q，可得到 O(n√q+q) 量级的端点移动，常用 B≈√n 是 q≈n 时的选择。

复杂度与接口排序 O(q log q)，移动 O(n²/B+qB)，空间 O(n+q+值域)。本实现仅处理静态不同数询问，修改

莫队另需时间维。

    int l, r, id;
};
vector<int> distinct_mo(const vector<int> &a, vector<Query> qs, int kinds) {
    int n = a.size();
    int B = max(1, int(n / sqrt(max(1, int(qs.size())))));
    sort(qs.begin(), qs.end(), [&](Query x, Query y) {
        int bx = x.l / B, by = y.l / B;
        if (bx != by)
            return bx < by;
        return (bx & 1) ? x.r > y.r : x.r < y.r;
    });
    vector<int> cnt(kinds), ans(qs.size());
    int L = 0, R = -1, cur = 0;
    auto add = [&](int p) {
        if (cnt[a[p]]++ == 0)
            ++cur;
    };
    auto del = [&](int p) {
        if (--cnt[a[p]] == 0)
            --cur;
    };
    for (auto q : qs) {
        while (L > q.l)
            add(--L);
        while (R < q.r)
            add(++R);
        while (L < q.l)
            del(L++);
        while (R > q.r)
            del(R--);
        ans[q.id] = cur;
    }
    return ans;
}

例题4.3 Barkley II MEX 分段与离线不同数查询

2023 CCPC 桂林 I

问题选择一个连续区间，使其中不同值数量减去 MEX 最大。MEX 为最小没出现的非负整

数。

解法枚举候选 x，把所有 x 出现的位置当成切点，只考虑不含 x 的极长区间。

一个区间不含 x，故真实 MEX≤x。以“不同值数−x”更新答案不会高估。真实最优区间的 MEX=t 时，在 x=t 这一轮扩展到极长区间不会损失。 收集所有候选区间，按右端点排序，用 Fenwick 维护每个数最后出现位置上的 1。处理 a[r] 时撤掉旧 last[a[r]]，在 r 放 1。 区间 [l,r] 的不同值数就是 Fenwick.sum(r)−Fenwick.sum(l−1)。MEX 不超过 n，只需枚举 0..n。

正确性任意候选得分 D−x≤D−真实MEX，所以不会产生虚假上界。取真实最优 MEX 的候选

时，极长扩展增加或保持不同值数，且仍缺失该 MEX，能够覆盖最优解。查询数等于每个值 出现次数加一个，合计 O(n)。

示例推演a=[0,2,2,3]。当 x=1 时整段不含 1，不同值有 3 类，得分 2。扫描到 r=4 时，只在下

标 1、3、4 放 1，查询任意左端点都可正确处理重复的 2。

实现要点不要枚举所有 O(n²) 区间。题面值域大也不需要枚举到最大 a[i]；只记录≤n 的

MEX 切点，扫描时所有值仍参与不同值计数。

复杂度O(n log n) 时间，O(n) 个候选查询，空间 O(n)。

练习建议先做静态不同数区间查询，再实现生成候选区间；对所有 n≤8 数组暴力核对。

例题4.4 Trapping Rain Water 从双指针到动态单调栈

2023 ICPC 南京 M

问题柱高数组中每次仅增加一个位置的高度，操作后求可接雨水总量。

解法静态水位是 min(前缀最大,后缀最大)。对每个位置，两边最大值中至少一边等于全局最

大 M，因此水位也等于前缀最大+后缀最大−M。 总水量等于前缀最大之和+后缀最大之和−nM−柱高总和。现在只需动态维护两套前后缀 纪录高。 用 set 保存每段前缀最大开始的下标。提高 p 后，若超过旧前缀最大，就截断 p 所在段， 并删除右侧被新高度压过的纪录。后缀同理反向处理。 维护每个常值段的高度乘长度之和。一次可能删除很多节点，但每次修改最多加入一个新 纪录。

正确性前缀最大从左向右不降，一旦某条纪录被更高的后起位置淘汰，它不会在之后仅增高

的修改中重新产生。新增纪录总数 O(n+q)，所以所有删除总数同阶。

示例推演柱高 [3,0,2,0,4] 的水量为 7。把中间高度 2 提到 5 后，前缀最大变为 [3,3,5,5,5]，后

缀最大为 [5,5,5,4,4]，用总和公式得到 7；不能只重算被修改的一格。

实现要点只增不减是摊还证明的核心，允许降低高度后上述删除策略失效。修改要更新柱高

总和、全局最大以及两个方向的段边界。

复杂度O((n+q) log(n+q)) 总时间，空间 O(n+q)。

练习建议先练“单点只增后的前缀最大之和”，用 O(n) 重算做对拍，再加入后缀。

例题4.5 Activity Rehearsal 用依赖树压缩队列模拟

2025 CCPC 济南 L

问题排列入队，每次取队头两项，较大者输出，较小者放队尾，共 n−1 次。支持交换原数组

两项，以及查询第 l..r 次输出之和。

解法把队列过程展开成一个延长数组 a[1..2n−1]，第 i 次操作产生 a[n+i]=min(a[2i−1],a[2i])，

后，父子编号约为 j 与 2j、2j+1，深度是对数级。叶子修改只影响祖先，全部其余输出不变。

加。别复制队列跑完整 n 次来回答每个询问。

5动态规划与状态压缩

动态规划把对未来影响相同的历史合并为一个状态。状态充分性决定递推是否成立，初始 化与依赖顺序决定实现是否正确。本章依次讨论线性、区间、背包、集合和数位状态。

5.1Kadane 与两个不重叠子段

最大子段和的状态是“必须在当前位置结束”的最优值，转移决定接上前一段还是从当前 元素重新开始。最大总答案与结尾状态要分别维护。

复杂度与接口O(n)，空间单段 O(1)，两段 O(n)。

C++17
ll kadane(const vector<ll> &a) {
    assert(!a.empty());
    ll end = a[0], best = a[0];
    for (int i = 1; i < (int)a.size(); i++)
        end = max(a[i], end + a[i]), best = max(best, end);
    return best;
}
ll two_subarrays(const vector<ll> &a) {
    int n = a.size();
    assert(n >= 2);
    vector<ll> L(n), R(n);
    ll e = a[0];
    L[0] = e;
    for (int i = 1; i < n; i++)
        e = max(a[i], e + a[i]), L[i] = max(L[i - 1], e);
    e = a[n - 1];
    R[n - 1] = e;
    for (int i = n - 2; i >= 0; i--)
        e = max(a[i], e + a[i]), R[i] = max(R[i + 1], e);
    ll ans = -INF;
    for (int i = 0; i < n - 1; i++)
        ans = max(ans, L[i] + R[i + 1]);
    return ans;
}

实现要点全负数组不能初始化答案为 0，除非题目允许空子段。接口要求数组非空。

允许空段时可以把结尾状态截为零；要求非空时不能把全负数组答案变成零。两段不重叠 可预处理左侧最优与右侧最优，枚举分界组合。

5.2LIS 与双序列动态规划

LIS 的 tails[len] 维护长度为 len+1 的递增子序列最小末尾。更小末尾只会给后续元素更多 选择，所以可以压缩为一个数。严格递增使用 lower_bound，非降使用 upper_bound。

复杂度与接口LIS O(n log n)，LCS O(nm)，滚动数组 O(m) 空间。

C++17
int lis(const vector<ll> &a) {
    vector<ll> t;
    for (ll x : a) {
        auto it = lower_bound(t.begin(), t.end(), x);
        if (it == t.end())
            t.push_back(x);
        else
            *it = x;
    }
    return t.size();
}
int lcs(const string &a, const string &b) {
    vector<int> d(b.size() + 1);
    for (char x : a) {
        int old = 0;
        for (int j = 1; j <= (int)b.size(); j++) {
            int save = d[j];
            d[j] = x == b[j - 1] ? old + 1 : max(d[j], d[j - 1]);
            old = save;
        }
    }
    return d.back();
}

实现要点严格递增用 lower_bound，非下降用 upper_bound。tails 不是实际子序列；要还原必

须记录前驱。滚动 LCS 需要保存左上格旧值。 LCS、编辑距离和交错字符串则同时记两个前缀长度。滚动数组应确认每格读取的是上一 行还是本行，遍历方向随依赖关系决定。

5.3区间 DP 与最长回文子序列

区间 DP 的状态只描述一段连续区间，先算短区间再算长区间。转移可以合并左右端，也 可以枚举切分点。最长回文子序列相等端点可一同选入，否则去掉一侧取较优。

复杂度与接口回文子序列 O(n²) 时间和空间；扰乱字符串朴素 O(n⁴)。

C++17
int lps(const string &s) {
    int n = s.size();
    if (!n)
        return 0;
    vector<vector<int>> d(n, vector<int>(n));
    for (int l = n - 1; l >= 0; l--) {
        d[l][l] = 1;
        for (int r = l + 1; r < n; r++)
            d[l][r] = s[l] == s[r]
                          ? 2 + (l + 1 <= r - 1 ? d[l + 1][r - 1] : 0)
                          : max(d[l + 1][r], d[l][r - 1]);
    }
    return d[0][n - 1];
}

实现要点子序列不连续；回文子串是另一类问题。n=0 要返回 0，不能访问 dp[0][−1]。

矩阵连乘、区间合并费用等枚举切分时通常为 O(n³)。没有四边形不等式等证明，不要擅 自把最优分界限制在相邻状态之间。

ll knapsack01(int W, const vector<pair<int, ll>> &items) {
    vector<ll> d(W + 1);
    for (auto [w, v] : items)
        for (int c = W; c >= w; c--)

}

}

5.5多重背包与分组背包

背包首先要决定物品能用几次以及每组能选几件。多重背包可以把数量拆成二进制包，再 使用 0 1 背包；分组背包的转移必须从处理该组之前的状态出发。 数量 s 拆为 1、2、4……和剩余部分，每个包的重量和价值同时乘包内数量。拆出的包可 表示 0..s 的任意数量。分组背包中，先保存 old=dp，再让该组所有物品从 old 转移，避免同组 多选。恰好装满时初始化 dp[0]=0、其他 −INF；容量不超过时可全部初始化零。

正确性二进制包的可表示范围逐段连续扩张，覆盖每一种合法取件数。old 隔离上一组状态，

使每次新增选择恰好来自当前组的一个物品；允许不选时保留旧 dp。

复杂度与接口二进制拆分 O(WΣlog(s_i+1))，分组背包 O(W×总物品数)，空间 O(W)。重量须为正；无限零

重量正价值物品会使最优值无界。

C++17
void bounded_item(vector<ll> &dp, int w, ll v, int s) {
    int W = int(dp.size()) - 1;
    for (ll k = 1; s > 0; k *= 2) {
        int take = int(min<ll>(k, s));
        s -= take;
        ll weight = 1LL * take * w, value = take * v;
        if (weight > W)
            continue;
        for (int c = W; c >= weight; --c)
            dp[c] = max(dp[c], dp[c - int(weight)] + value);
    }
}
void group_items(vector<ll> &dp, const vector<pair<int, ll>> &group) {
    auto old = dp;
    int W = int(dp.size()) - 1;
    for (auto [w, v] : group)
        for (int c = w; c <= W; ++c)
            dp[c] = max(dp[c], old[c - w] + v);
}

实现要点模板使用“容量不超过”语义。恰好装满或负价值时，应对不可达状态做保护，不

能让 −INF 加上价值伪装成可达。计数问题还要分清组合与排列：物品在外通常数无序组合， 容量在外可能数有序序列。

5.6集合状压 DP 的基础骨架

集合状压先证明未来只与当前 mask 有关。分配问题中已选对象数量 popcount(mask) 决定 下一位，无需再存阶段；旅行路线还依赖当前位置，因此必须增加 last。

复杂度与接口O(n2ⁿ)，空间 O(2ⁿ)，一般 n≤20。

C++17
ll assignment(const vector<vector<ll>> &cost) {
    int n = cost.size();
    assert(n <= 20);
    int S = 1 << n;
    vector<ll> d(S, INF);
    d[0] = 0;
    for (int mask = 0; mask < S; mask++) {
        int i = __builtin_popcount((unsigned)mask);
        if (i == n)
            continue;
        for (int j = 0; j < n; j++)
            if (!(mask >> j & 1))
                d[mask | 1 << j] =
                    min(d[mask | 1 << j], d[mask] + cost[i][j]);
    }
    return d.back();
}

实现要点先估算状态数再开数组。有限棋盘题把坐标关系预处理成合法位转移，不应在每个

状态里重新写几何判断。 棋盘状态、子集分配与轮廓 DP 的掩码含义各不相同。位压缩只负责编码；时间仍取决于 状态数与转移数，空间还需乘上全部附加维度。

5.7集合与末尾共同构成的状态

遍历一组地点的路径问题，未来既依赖访问过的集合，也依赖当前停在哪个点。只记录 mask 会合并后继代价不同的状态，必须增加 last。 令 dp[mask][u] 为从指定起点出发，访问集合恰为 mask、最后停在 u 的最小代价。转移到 未访问 v，得到 dp[mask|1<<v][v]。若要求回到起点，最后再加回边费用；如果只找路径则直 接取末尾最小值。

正确性每条合法路径都有唯一的最后一步，删去它便得到相应前驱状态。状态包含所有影响

未来的信息，枚举全部前驱不会遗漏也不会引入重复访问。

复杂度与接口O(n²2^n) 时间、O(n2^n) 空间。代码固定从 0 出发，求访问全部点的最短路径，不要求回到

0；n 通常不超过约 20。

C++17
ll subset_path(const vector<vector<ll>> &w) {
    int n = w.size();
    assert(n > 0 && n < 25);
    int S = 1 << n;
    vector<vector<ll>> dp(S, vector<ll>(n, INF));
    dp[1][0] = 0;
    for (int mask = 1; mask < S; ++mask)
        for (int u = 0; u < n; ++u)
            if (dp[mask][u] != INF)
                for (int v = 0; v < n; ++v)
                    if (!(mask & (1 << v))) {
                        if (w[u][v] == INF)
                            continue;
                        int nxt = mask | (1 << v);
                        dp[nxt][v] = min(dp[nxt][v], dp[mask][u] + w[u][v]);
                    }
    return *min_element(dp.back().begin(), dp.back().end());
}

5.8子集枚举与 SOS DP

小集合编码为掩码后，既能枚举其子集，也能把子集统计量批量汇总到超集。可行规模主 要由有效位数 B 决定，而非输入对象总数。 枚举 mask 的非空子集，令 sub=(sub−1)&mask。若要对每个 mask 枚举所有子集，总次数 是 3^B，因为每一位只有“不在 mask、在 mask 不在 sub、在 sub”三种状态。SOS DP 则逐位 决定是否去掉当前位，把 f[mask] 变成所有 sub mask ⊆ 的总和。

正确性处理前 i 位后，dp[mask] 累计了只允许在这 i 位上删位的所有子集。下一位同时保留

含位状态和不含位状态，两类互不重复。处理全部位即得到完整子集和。

复杂度与接口子集和 O(B2^B)，空间 O(2^B)。本实现求整数和；求最大值时把加法替换成 max，单位元随

之调整。

vector<ll> subset_sum_transform(vector<ll> f, int B) {
    assert(int(f.size()) == (1 << B));
    for (int b = 0; b < B; ++b)
        for (int mask = 0; mask < (1 << B); ++mask)
            if (mask & (1 << b))
                f[mask] += f[mask ^ (1 << b)];
    return f;
}

5.9数位 DP 的双边界状态

数位 DP 按高位到低位处理，把上下界限制、前导零和题意自动机状态拆开。只有紧贴边 界时下一位范围受限制，脱离边界后才可复用相同状态。 本节 digit_cost 处理等长十进制边界 L、R，在 L≤x≤R 中最小化 x 与两端逐位相等的次数 之和。每位代价为两次相等判断，状态仅需位置和两个贴边标记；若加入余数、数字种类或禁 串限制，需扩充状态。

复杂度与接口十进制位数 D，状态 O(D)，转移 O(10D)。

C++17
int digit_cost(string L, string R) {
    assert(L.size() == R.size());
    int n = L.size();
    vector<array<array<int, 2>, 2>> memo(n);
    for (auto &x : memo)
        for (auto &y : x)
            y.fill(-1);
    function<int(int, int, int)> dfs = [&](int p, int tl, int tr) {
        if (p == n)
            return 0;
        int &ans = memo[p][tl][tr];
        if (ans >= 0)
            return ans;
        ans = 1000000;
        int lo = tl ? L[p] - '0' : 0, hi = tr ? R[p] - '0' : 9;
        for (int x = lo; x <= hi; x++)
            ans = min(ans, (x == L[p] - '0') + (x == R[p] - '0') +
                               dfs(p + 1, tl && (x == lo), tr && (x == hi)));
        return ans;
    };
    return dfs(0, 1, 1);
}

降为假后不能重新变真。 不含某个模式串时可以把 KMP 状态接入数位 DP；整除条件接余数。零是否算合法数 字、前导零是否参与模式匹配必须先在状态定义中决定。

ll free_knapsack(vector<pair<int, ll>> a, int k, int W) {
    int n = a.size();
    assert(0 <= k && k <= n);
    sort(a.begin(), a.end(),
         [](auto x, auto y) { return x.first > y.first; });
    vector<ll> pref(n + 1, -INF);
    priority_queue<ll, vector<ll>, greater<ll>> q;
    ll sum = 0;
    if (!k)
        pref[0] = 0;
    for (int i = 1; i <= n; i++) {
        q.push(a[i - 1].second);
        sum += a[i - 1].second;
        if ((int)q.size() > k)
            sum -= q.top(), q.pop();
        if ((int)q.size() == k)
            pref[i] = sum;
    }
    vector<ll> dp(W + 1);
    ll ans = pref[n];
    for (int i = n - 1; i >= 0; i--) {
        auto [w, v] = a[i];
        for (int c = W; c >= w; c--)
            dp[c] = max(dp[c], dp[c - w] + v);
        if (pref[i] != -INF)
            ans = max(ans, pref[i] + dp[W]);
    }
    return ans;
}

6.1并查集与离线连通

普通 DSU 维护无向可连接关系，每次合并是把两个等价类合成一个。路径压缩和按大小 合并给出近常数的均摊成本；分量摘要如大小、最小值可以随合并同步更新。

复杂度与接口总复杂度近似 O((n+m)α(n))；离线排序额外 O(m log m)。

C++17
struct DSU {
    vector<int> p, sz;
    explicit DSU(int n) : p(n), sz(n, 1) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (sz[a] < sz[b])
            swap(a, b);
        p[b] = a;
        sz[a] += sz[b];
        return true;
    }
};

6.2带奇偶关系的并查集

关系 DSU 除父亲外，还保存每点到父亲的异或差。路径压缩时累计到根的差值，合并两 根时用已知关系反解新根边的差；同根时直接验证关系是否一致。

复杂度与接口近似 O(α(n)) 每条约束，空间 O(n)。

C++17
struct ParityDSU {
    vector<int> p, sz, xr;
    explicit ParityDSU(int n) : p(n), sz(n, 1), xr(n) {
        iota(p.begin(), p.end(), 0);
    }
    int find(int x) {
        if (p[x] == x)
            return x;
        int old = p[x];
        p[x] = find(old);
        xr[x] ^= xr[old];
        return p[x];
    }
    bool link(int a, int b, int v) {
        int ra = find(a), rb = find(b), d = xr[a] ^ xr[b] ^ v;
        if (ra == rb)
            return d == 0;
        if (sz[ra] < sz[rb])
            swap(ra, rb);
        p[rb] = ra;
        xr[rb] = d;
        sz[ra] += sz[rb];
        return true;
    }
};

实现要点同根时要检查原有关系是否与新约束冲突。它可解决成对相同相反关系，但任意析

取条件仍需要 2 SAT。 普通 DSU 合并只关心能否连接，关系 DSU 还必须关心连接后的相对状态。若题目关系为 模 k 加法，可把 xor 改成模 k 势能；每一步符号都需要重新推导。

6.3BFS 多源搜索与洪水填充

无权图每条边代价相同，FIFO 队列按距离层扩展，所以首次到达即最短。多源 BFS 将所 有起点距离设为零，等价于增加一个零费用超级源，但不需要实际建点。

C++17
vector<int> bfs(const vector<vector<int>> &g, const vector<int> &sources) {
    vector<int> d(g.size(), -1);
    queue<int> q;
    for (int s : sources)
        if (d[s] < 0)
            d[s] = 0, q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u])
            if (d[v] < 0)
                d[v] = d[u] + 1, q.push(v);
    }
    return d;
}

实现要点入队时标记，避免同层重复入队。最短路径的全部方案需要记录同层所有前驱，不

能第一次到达就丢弃后续前驱。 状态可以是位置加钥匙 mask，也可以是两个角色的位置对。复杂度由展开后的状态数与 转移数决定，不能只用原图 n、m 估算。 边界连通区域可先从边界搜索，再处理未访问内部；最远海洋问题可由全部陆地同时出 发。删除砖块可倒序恢复并连接屋顶虚拟点。网格搜索深度可能达到格子总数，长链输入应优 先采用迭代实现。

6.40 1 BFS

边权仅为 0 或 1 时，双端队列把零费用松弛放在前端、一费用放在后端，使队列保持距离 近似分层。它处于 BFS 与 Dijkstra 之间，省掉优先队列的对数因子。

复杂度与接口O(n+m)，空间 O(n)。

C++17
vector<ll> bfs01(const vector<vector<pair<int, int>>> &g, int s) {
    vector<ll> d(g.size(), INF);
    deque<pair<ll, int>> q;
    d[s] = 0;
    q.push_front({0, s});
    while (!q.empty()) {
        auto [du, u] = q.front();
        q.pop_front();
        if (du != d[u])
            continue;
        for (auto [v, w] : g[u])
            if (d[v] > du + w) {
                assert(w == 0 || w == 1);
                d[v] = du + w;
                if (w)
                    q.push_back({d[v], v});
                else
                    q.push_front({d[v], v});
            }
    }
    return d;
}

实现要点边权必须只有 0 或 1。不能在第一次入队时永久锁定节点，因为之后可能得到更短

距离。 方向改变次数、免费与收费通道都可能形成 0 1 边。边权为任意正整数时双端队列的排序 性质消失，应改用 Dijkstra。 二维接雨水需按当前水位的小根堆从边界扩展，每个新格水位取外侧水位与格高的较大 者。它是瓶颈最短路式搜索，不能使用只适合 0 1 边权的双端队列规则。

6.5Dijkstra 与状态扩展

Dijkstra 每次确定暂定距离最小的顶点。由于边权非负，经尚未确定的顶点绕行不会缩短 它的距离。堆中允许保留过时条目，弹出时用当前 dist 检查并跳过。 图 6.1 最短路径的松弛与顶点确定

复杂度与接口O((n+m) log n)，空间 O(n+m)；扩展图按状态数重算。

C++17
vector<ll> dijkstra(const vector<vector<pair<int, ll>>> &g, int s) {
    vector<ll> d(g.size(), INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>,
                   greater<pair<ll, int>>>
        q;
    d[s] = 0;
    q.push({0, s});
    while (!q.empty()) {
        auto [du, u] = q.top();
        q.pop();
        if (du != d[u])
            continue;
        for (auto [v, w] : g[u]) {
            assert(w >= 0);
            if (w >= INF || du > INF - w)
                continue;
            if (d[v] > du + w)
                d[v] = du + w, q.push({d[v], v});
        }
    }
    return d;
}

实现要点有负边不能套。本实现 INF=2⁶²，要求真实可达距离小于 INF，且边权非负。A 星还

需要启发函数不会高估；四邻格子用曼哈顿距离且每步费用至少为 1 时可用。 分层图将已用优惠次数、交通方式等限制写入状态，再在扩展图上求最短路。A 星还依赖 不高估剩余代价的启发函数，并须配合正确的更新与终止规则。 最小体力路径把路径代价的加法改为 max(当前瓶颈,新边权)，仍具有扩展后代价不减的性 质。钥匙迷宫可用 (格子,mask) 做 BFS；电动车可用 (城市,电量) 做 Dijkstra，分别为充电和行 驶建边。

6.6Bellman Ford 与 Floyd

Bellman Ford 按边松弛，限定最多 k 条边时每轮必须读取上一轮副本；否则同一轮可能串 联多条边。Floyd 按允许的中间点集合逐步扩展，循环顺序 k 在最外层。

复杂度与接口Bellman Ford O(nm)，Floyd O(n³) 与 O(n²) 空间。

C++17
struct Edge {
    int u, v;
    ll w;
};
pair<vector<ll>, bool> bellman(int n, vector<Edge> es, int s) {
    vector<ll> d(n, INF);
    d[s] = 0;
    bool changed = false;
    for (int k = 0; k < n; k++) {
        changed = false;
        for (auto e : es)
            if (d[e.u] != INF) {
                i128 nd = (i128)d[e.u] + e.w;
                assert(-INF < nd && nd < INF);
                if (nd < d[e.v])
                    d[e.v] = (ll)nd, changed = true;
            }
        if (!changed)
            break;
    }
    return {d, changed}; // true 表示起点可达负环。
}
void floyd(vector<vector<ll>> &d) {
    int n = d.size();
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (d[i][k] != INF && d[k][j] != INF) {
                    i128 nd = (i128)d[i][k] + d[k][j];
                    assert(-INF < nd && nd < INF);
                    d[i][j] = min(d[i][j], (ll)nd);
                }
}

实现要点SPFA 最坏复杂度仍为 O(nm)，不能把它当作稳定线性算法。有负环时最短路可能

不存在；要说明负环是否必须从起点可达。 SPFA 是队列化松弛策略，不具有一般线性最坏界。若从单源检测可达负环，可做 n 轮松 弛；检测全图任意负环可引入超级源。不可达距离与 INF 相加前必须保护。

6.7Prim 与 Kruskal 最小生成树

Kruskal 按边权从小到大加入不成环的边。当前各连通分量形成若干棵树，加入连接不同 分量的最小边，存在某个最优生成树包含这一步选择。 Prim 按割性质选择连接当前树与外部的最小边。稀疏图可用堆维护，稠密图可扫描最小 跨边，时间为 O(n²)。Prim 比较接入树的单条边权，Dijkstra 比较从源点累计的路径长度。

邻接表，每边双向加入；返回 i128 总权，不连通时为空 optional。

optional<ll> kruskal(int n, vector<Edge> es) {
    sort(es.begin(), es.end(), [](auto a, auto b) { return a.w < b.w; });
    DSU d(n);
    ll ans = 0;
    int used = 0;
    for (auto e : es)
        if (d.unite(e.u, e.v))
            ans += e.w, ++used;
    if (used != n - 1)
        return nullopt;
    return ans;
}
optional<i128> prim(const vector<vector<pair<int, ll>>> &g) {
    int n = g.size();
    if (!n)
        return i128(0);
    vector<int> used(n);
    int count = 0;
    i128 cost = 0;
    priority_queue<pair<ll, int>, vector<pair<ll, int>>,
                   greater<pair<ll, int>>>
        q;
    q.push({0, 0});
    while (!q.empty()) {
        auto [w, u] = q.top();
        q.pop();
        if (used[u])
            continue;
        used[u] = 1;
        ++count;
        cost += w;
        for (auto [v, weight] : g[u])
            if (!used[v])
                q.push({weight, v});
    }
    if (count != n)
        return nullopt;
    return cost;
}

实现要点不连通时返回无解。最小生成树也是最小瓶颈生成树，反向不成立；若只求瓶颈可

以只保留最后一条选中边权。 最小生成树最小化全部选边总和，最短路树最小化源到各点的距离，两者不同。离线阈值 连通查询可以同样按边权扫描，却不需要真的选出生成树边。 供水题给每个村庄与虚拟节点连接打井费用，把建设选择统一成 MST。邻接表与链式前 向星都是建图方式；重边、自环、无向边双向插入和数组容量属于输入建模，不能忽略。

6.8离线阈值与状态图建模

边权阈值连通可将边和询问按阈值排序，逐步加入边并回答 DSU 查询。秘密传播一类时 间分组必须处理同一时间的全部连通关系，再清除不与已知源连接的临时信息，不能让未传播 成功的关系永久保留。 状态图将题目限制编码在节点中：钥匙集合、剩余优惠次数、角色位置与已使用资源都是 常见维度。先证明这些状态足以决定下一步，再选择 BFS、0 1 BFS 或 Dijkstra。双向 BFS 适 合可逆且能正确列出反向前驱的搜索；A 星还要求启发不高估剩余代价。

7.1拓扑排序与 DAG DP

DAG 中每条边规定一种先后关系。拓扑序让所有前驱先处理，适合最长路、方案数和依 赖完成时间。Kahn 算法每次取入度零节点，最后处理数量小于 n 表明存在环。

复杂度与接口O(n+m)，最小字典序为 O((n+m) log n)。

C++17
vector<int> topo(const vector<vector<int>> &g) {
    int n = g.size();
    vector<int> deg(n), ord;
    queue<int> q;
    for (auto &vs : g)
        for (int v : vs)
            ++deg[v];
    for (int i = 0; i < n; i++)
        if (!deg[i])
            q.push(i);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ord.push_back(u);
        for (int v : g[u])
            if (--deg[v] == 0)
                q.push(v);
    }
    if ((int)ord.size() != n)
        return {};
    return ord;
}

实现要点出边方向必须是前置任务到后续任务。DAG 路径计数先定起点、终点与是否包含零

边路径。功能图的剥叶和环处理与普通 DAG 不完全相同。 队列中同时存在多个可选节点是拓扑序不唯一的信号。若需要字典序最小拓扑序，把队列 换成小根堆；计数不同拓扑序不能靠一个队列直接完成。 食物链计数可用 DAG 方案数，反向盖章可以维护尚未满足的字符依赖。每点出度为一的 功能图，可先剥去非环节点，再逐个处理环，树枝信息按删除顺序汇总。最大邀请人数还需比 较最长环与二环所接树枝；周期交通状态可按余数与已访问状态判断循环。

7.2强连通分量与缩点 DAG

有向图中的“相互可达”是一种等价关系。把每个最大相互可达集合压成一个点，原图的 所有环都被吸收，剩下的图一定无环。随后可以用拓扑序做路径 DP。 本节采用 Kosaraju 算法。第一遍在原图记录 DFS 完成顺序，第二遍按其逆序搜索反图， 每次搜索得到一个强连通分量。显式栈可避免长链图耗尽递归栈。

正确性若缩点图中仍有环，环上各分量将相互可达，与“不同强连通分量”矛盾。第二遍的

起点来自尚未处理分量中适当的拓扑位置，反图搜索不会越过未处理分量的边界，却能覆盖同 一分量。 图 7.1 强连通分量压缩为有向无环图

vector<int> scc(const vector<vector<int>> &g) {
    int n = g.size();
    vector<vector<int>> rg(n);
    for (int u = 0; u < n; ++u)
        for (int v : g[u])
            rg[v].push_back(u);
    vector<int> seen(n), order;
    for (int s = 0; s < n; ++s)
        if (!seen[s]) {
            vector<pair<int, int>> st{{s, 0}};
            seen[s] = 1;
            while (!st.empty()) {
                int u = st.back().first;
                int &i = st.back().second;
                if (i == int(g[u].size())) {
                    order.push_back(u);
                    st.pop_back();
                } else {
                    int v = g[u][i++];
                    if (!seen[v]) {
                        seen[v] = 1;
                        st.push_back({v, 0});
                    }
                }
            }
        }
    vector<int> comp(n, -1);
    int id = 0;
    reverse(order.begin(), order.end());
    for (int s : order)
        if (comp[s] == -1) {
            vector<int> st{s};
            comp[s] = id;
            while (!st.empty()) {
                int u = st.back();
                st.pop_back();
                for (int v : rg[u])
                    if (comp[v] == -1) {
                        comp[v] = id;
                        st.push_back(v);
                    }
            }
            ++id;
        }
    return comp;
}

实现要点SCC 适用于有向图；无向连通块只需 DFS 或 DSU。点权全部非负时，可以把分量

权求和；有负权、不能重复经过或存在资源限制时，压成“总点权”需要重新证明。缩点边去 重可减小常数，也可保留重边并准确计算入度。

7.3桥与割点的 lowlink 判定

无向图中，删除一条边让连通分量数增加，该边是桥；删除一个点让连通分量数增加，该 点是割点。两者都利用 DFS 子树是否能通过返祖边绕回上方。 dfn[u] 是访问时间，low[u] 是从 u 的 DFS 子树经树边向下、再至多用一条返祖边能到达的 最小时间。树边 u→v 是桥当且仅当 low[v]>dfn[u] 。非根 u 是割点当某个孩子满足 low[v]≥dfn[u]；DFS 根则必须有至少两个孩子。

正确性严格大于表示子树连 u 自身都无法绕回，父子边不可替代；大于等于表示去掉 u 后，

该子树无法到达 u 的祖先。根没有祖先，必须单独根据独立搜索分支数量判断。

复杂度与接口O(n+m) 时间和空间。图的边有唯一编号，同一无向边的两个方向共用编号；允许平行边。

C++17
struct Lowlink {
    vector<vector<pair<int, int>>> g;
    vector<int> dfn, low, cut, bridges;
    int timer = 0;
    Lowlink(int n) : g(n), dfn(n), low(n), cut(n) {}
    void edge(int u, int v, int id) {
        g[u].push_back({v, id});
        g[v].push_back({u, id});
    }
    void dfs(int u, int parent_edge = -1) {
        dfn[u] = low[u] = ++timer;
        int children = 0;
        for (auto [v, id] : g[u]) {
            if (id == parent_edge)
                continue;
            if (!dfn[v]) {
                ++children;
                dfs(v, id);
                low[u] = min(low[u], low[v]);
                if (low[v] > dfn[u])
                    bridges.push_back(id);
                if (parent_edge != -1 && low[v] >= dfn[u])
                    cut[u] = 1;
            } else
                low[u] = min(low[u], dfn[v]);
        }
        if (parent_edge == -1 && children > 1)
            cut[u] = 1;
    }
    void run() {
        for (int u = 0; u < int(g.size()); ++u)
            if (!dfn[u])
                dfs(u);
    }
};

实现要点不能只跳过父节点：平行边中另一条边仍是合法返祖边。此紧凑版使用递归，长链

应换成显式栈或确保运行环境的栈容量。删除所有桥后做连通块，可得到边双连通分量及桥 树。

    vector<vector<int>> g;
    vector<int> L, R, d;
    HopcroftKarp(int n, int m) : n(n), m(m), g(n), L(n, -1), R(m, -1), d(n) {}
    bool bfs() {
        queue<int> q;
        fill(d.begin(), d.end(), INT_MAX);
        shortest = INT_MAX;
        for (int u = 0; u < n; u++)
            if (L[u] < 0)
                d[u] = 0, q.push(u);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            if (d[u] >= shortest)
                continue;
            for (int v : g[u]) {
                if (R[v] < 0)
                    shortest = d[u] + 1;
                else if (d[R[v]] == INT_MAX)
                    d[R[v]] = d[u] + 1, q.push(R[v]);
            }
        }
        return shortest != INT_MAX;
    }
    bool dfs(int u) {
        for (int v : g[u]) {
            if ((R[v] < 0 && d[u] + 1 == shortest) ||
                (R[v] >= 0 && d[R[v]] == d[u] + 1 && dfs(R[v]))) {
                L[u] = v;
                R[v] = u;
                return true;
            }
        }
        d[u] = INT_MAX;
        return false;
    }
    int solve() {
        int ans = 0;
        for (int x : L)
            ans += x >= 0;
        while (bfs())
            for (int u = 0; u < n; u++)
                if (L[u] < 0 && dfs(u))
                    ++ans;
        return ans;
    }
};

实现要点左右编号是独立的 0 开始。递归 DFS 在极长交替路中要注意栈空间；这与普通并查

集或相同相反约束不同。 匹配只解决一对一选择约束。一般图没有左右部时不能直接使用；一项可匹配多次可改成 容量或复制节点。残余图的可达性还能判断可替换选择与最小点覆盖。

7.5最大流与最小割建模

最大流描述带容量的资源传递：除源汇外每个节点流入等于流出。残余图保存继续增加流 量以及撤销旧分配的可能。最小割则把节点分成源侧与汇侧，割掉的容量总和限制任何可行 流。 Dinic 先在残余图中 BFS 分层，再沿层数递增的边发送阻塞流；本轮无法继续增广后重新 分层。当前弧记录已处理的边，避免反复扫描。每次送流同时更新正向与反向残余容量。

正确性每次增广保持容量限制和流量守恒。终止时残余图中源无法到汇，源可达集合到外部

的正向边全部饱和，反向跨割流为零，因此当前流等于这个割的容量，达到最优。

复杂度与接口一般图最坏 O(V²E)，空间 O(V+E)；二分图单位容量通常更快。接口拒绝自环，平行边可直接

加入；容量和总流量应在 ll 范围内。

C++17
struct Dinic {
    struct E {
        int to, rev;
        ll cap;
    };
    vector<vector<E>> g;
    vector<int> level, ptr;
    Dinic(int n) : g(n), level(n), ptr(n) {}
    void add(int u, int v, ll c) {
        assert(u != v && c >= 0);
        E a{v, int(g[v].size()), c};
        E b{u, int(g[u].size()), 0};
        g[u].push_back(a);
        g[v].push_back(b);
    }
    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        queue<int> q;
        q.push(s);
        level[s] = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (auto e : g[u])
                if (e.cap && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
        }
        return level[t] != -1;
    }
    ll dfs(int u, int t, ll f) {
        if (u == t)
            return f;
        for (int &i = ptr[u]; i < int(g[u].size()); ++i) {
            E &e = g[u][i];
            if (!e.cap || level[e.to] != level[u] + 1)
                continue;
            ll z = dfs(e.to, t, min(f, e.cap));
            if (!z)
                continue;
            e.cap -= z;
            g[e.to][e.rev].cap += z;
            return z;
        }
        return 0;
    }
    ll flow(int s, int t) {
        assert(s != t);
        ll ans = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (ll z = dfs(s, t, INF))
                ans += z;
        }
        return ans;
    }
};

实现要点边权是费用时不能直接当容量；最小费用流是另一种模型。所谓无限容量应超过所

有有限割的可能总和，又不能导致加法溢出。这里只给最大流，不把它作为所有铜牌题的必备 前置。

7.6二元逻辑约束与 2 SAT

奇偶 DSU 处理相同或相反关系；当条件变成“两个命题至少一个为真”，可以用 2 SAT。每个布尔变量拆成真、假两个文字，文字与其否定的编号相差一位。 子句 a 或 b 等价于 ¬a→b 与 ¬b→a。建立蕴含图，若某变量的真与假处于同一个 SCC，就 会互相强制，无法满足。否则按缩点拓扑顺序给相反文字赋值，可以构造一组解。

正确性矛盾时真能推出假、假也能推出真。无矛盾时在缩点 DAG 中从后向前选择尚未赋值

文字为真、其否定为假，可避免已选真命题指向假命题。本节按 Kosaraju 的分量顺序等价地 比较编号。

复杂度与接口O(n+m) 时间与空间。依赖前面的 scc；它给出的分量编号从拓扑源向汇增加，此约定不可换

成另一份 SCC 后仍沿用。

C++17
struct TwoSAT {
    int n;
    vector<vector<int>> g;
    TwoSAT(int n) : n(n), g(2 * n) {}
    void either(int i, int a, int j, int b) {
        int x = 2 * i + a, y = 2 * j + b;
        g[x ^ 1].push_back(y);
        g[y ^ 1].push_back(x);
    }
    vector<int> solve() {
        auto c = scc(g);
        vector<int> ans(n);
        for (int i = 0; i < n; ++i) {
            if (c[2 * i] == c[2 * i + 1])
                return {};
            ans[i] = c[2 * i + 1] > c[2 * i];
        }
        return ans;
    }
};

实现要点a、b 必须为 0 或 1，变量从 0 开始。返回空数组表示无解，要求 n>0。一个子句有

三个任意文字时已不是 2 SAT；不要用不完整拆边冒充原约束。作为伸展知识，在基本关系图 稳定后学习。

7.7图模型的适用边界

一对一选择使用匹配，可拆分且带数量上限的资源分配使用流，两个布尔文字组成的或约 束使用 2 SAT。一般图匹配与最小费用流需要更专门的算法，不能直接套用本章实现。 缩点、桥树与拓扑常作为后续 DP 的预处理。压缩时必须定义一个分量如何与外部交互： 能否任意选入口出口、能否收集全部点权、是否保持距离。只有证明这些语义后，“压成一个 点”才是正确算法。

例题7.1 缩点后的最大点权路径

例题7.5 Equivalent Rewriting 只保留最后赋值

2023 ICPC 南京 F

问题操作 i 把某些变量赋值为 i，初始顺序 1..n。求另一执行顺序，保证所有变量最终值相

同。

解法对每个变量记录原顺序最后一次修改它的操作 last。之前改过该变量的操作都必须在 last

之前。 这样得到的有向边从小编号指向大编号，原序列是一个拓扑序。问题变为能否找到不同的 拓扑序。 只需检查是否存在某对相邻操作 i、i+1 之间没有依赖边。有则交换这两项，其他相对次 序不变。 不用显式建立全部图：只检查操作 i 修改的变量里是否有 last 等于 i+1。

正确性交换相邻两项只改变它们的相对先后；没有从 i 到 i+1 的边时所有依赖仍满足。如果

每对相邻项都有边，就形成包含所有点的链，拓扑序只能唯一。

示例推演操作 1 改 x，操作 2 改 y，操作 3 改 x。约束只有 1→3，因此交换 1、2 后 [2,1,3] 仍

有 x=3、y=2。

实现要点不用将每个变量的所有修改两两连边，那会产生不必要的平方开销。未被最后操作

覆盖的赋值影响必须由 last 精确保留。

复杂度O(n+修改变量总数)，空间 O(变量总数)。

练习建议n≤8 枚举操作排列核对；再尝试给每次操作赋一般不同值，观察依赖条件为何仍成

立或何时改变。

例题7.6 I Just Want One More 匹配增量与残余可达

2023 ICPC 济南 E

问题在平衡二分图中恰好加一条左右两侧之间的边，使最大匹配数增加，求可以添加的边

解法先求最大匹配，完美匹配时答案为零。交替残余图中，未匹配边从左到右、匹配边从右

8树上动态规划与路径维护

根、父子关系与 DFS 序构成树上算法的基本结构。子树可映射为连续区间，路径可拆成 重链区间，换根 DP 则通过跨边转移联系所有根的答案。

8.1迭代树序与不相邻点最大和

树的父子顺序先由遍历建立，再逆序处理孩子。最大权独立集有选与不选两种状态：选 u 时孩子不能选；不选 u 时每个孩子可自由取最优。

复杂度与接口O(n)，空间 O(n)。

C++17
ll tree_independent(const vector<vector<int>> &g, const vector<ll> &w) {
    int n = g.size();
    if (!n)
        return 0;
    vector<int> p(n, -1), ord{0};
    p[0] = 0;
    for (int i = 0; i < n; i++) {
        int u = ord[i];
        for (int v : g[u])
            if (v != p[u])
                p[v] = u, ord.push_back(v);
    }
    vector<ll> yes = w, no(n);
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i], f = p[u];
        yes[f] += no[u];
        no[f] += max(yes[u], no[u]);
    }
    return max(yes[0], no[0]);
}

实现要点接口要求输入是连通无向树。选不选状态处理的是独立集，不是所有树 DP 的统一

状态；有负权时不选所有点也合法。 树上的状态需要明确“子树内部”和“与父亲相连的接口”。一般树与二叉树的差别主要 是孩子数，不能在每个点只处理左右两项。 非负权树的直径可由两次最远点搜索求得，无权树可用 BFS。二叉树平衡性通过高度自底 向上判断；完全性可由层序中首次缺少孩子的位置判定，完整子树的高度结构还可用于加速节 点计数。

8.2倍增 LCA 与树上距离

倍增 up[k][u] 保存 u 的 2^k 级祖先，先把深度较大者提到相同深度，再从高位到低位同时 跳过仍不同的祖先。最后的父亲就是 LCA。

复杂度与接口预处理 O(n log n)，LCA O(log n)，空间 O(n log n)。

C++17
struct LCA {
    int n, K;
    vector<int> dep;
    vector<vector<int>> up;
    LCA(const vector<vector<int>> &g, int root = 0)
        : n(g.size()), K(1), dep(n) {
        while ((1LL << K) <= n)
            ++K;
        up.assign(K, vector<int>(n, root));
        vector<int> p(n, -1), ord{root};
        p[root] = root;
        for (int i = 0; i < n; i++) {
            int u = ord[i];
            up[0][u] = p[u];
            for (int v : g[u])
                if (v != p[u])
                    p[v] = u, dep[v] = dep[u] + 1, ord.push_back(v);
        }
        for (int k = 1; k < K; k++)
            for (int v = 0; v < n; v++)
                up[k][v] = up[k - 1][up[k - 1][v]];
    }
    int get(int u, int v) const {
        if (dep[u] < dep[v])
            swap(u, v);
        int d = dep[u] - dep[v];
        for (int k = 0; k < K; k++)
            if (d >> k & 1)
                u = up[k][u];
        if (u == v)
            return u;
        for (int k = K - 1; k >= 0; k--)
            if (up[k][u] != up[k][v])
                u = up[k][u], v = up[k][v];
        return up[0][u];
    }
    int dist(int u, int v) const {
        return dep[u] + dep[v] - 2 * dep[get(u, v)];
    }
};

实现要点输入为从 0 编号的非空连通无权树；根祖先设为自身。加权树用根距离相加再减去

两倍 LCA 根距离。 树上距离为 depth[u]+depth[v]−2depth[lca]，加权树用根距离代替深度。二叉搜索树的比较 大小 LCA 解法依赖搜索树性质，不能用于一般树。 进入节点时记录 tin，完成全部后代后记录 tout，则子树对应 [tin,tout)。按 tin 存放点值 后，可用树状数组维护子树和。该连续性依赖 DFS 的进入、退出次序，普通 BFS 序不具有这 一性质。

8.3DFS 序与重链剖分

DFS 序将子树映射为单一区间；重儿子优先的 DFS 序还使每条重链连续，从而把任意路 径拆成 O(log n) 个区间，再接入区间数据结构。 第一遍计算父亲、深度、子树大小以及最大的孩子 heavy。第二遍优先走 heavy，并继承 链顶 top；轻儿子另开一条链。路径查询每次处理链顶较深的一侧，然后跳到该链顶的父亲， 直到两点同链。

正确性沿轻边向上时，进入的父子树规模至少翻倍：轻儿子的大小不超过父子树的一半。任

何根路径至多有 O(log n) 条轻边，所以拆出的区间数也是 O(log n)。子树在重儿子优先的 DFS 中依然连续。 图 8.1 重链连续性与子树区间

复杂度与接口预处理 O(n)，路径拆分 O(log n)，配合线段树为 O(log² n)；子树查询只需 O(log n)。代码采用

迭代遍历，g 为 0 下标无向树。

C++17
struct HLD {
    int n, timer = 0;
    vector<int> par, dep, sz, heavy, top, pos;
    HLD(const vector<vector<int>> &g, int root = 0)
        : n(g.size()), par(n, -1), dep(n), sz(n, 1), heavy(n, -1), top(n),
          pos(n) {
        vector<int> order{root};
        par[root] = root;
        for (int i = 0; i < n; ++i) {
            int u = order[i];
            for (int v : g[u])
                if (v != par[u]) {
                    par[v] = u;
                    dep[v] = dep[u] + 1;
                    order.push_back(v);
                }
        }
        for (int i = n - 1; i > 0; --i) {
            int u = order[i], p = par[u];
            sz[p] += sz[u];
            if (heavy[p] == -1 || sz[u] > sz[heavy[p]])
                heavy[p] = u;
        }
        vector<pair<int, int>> st{{root, root}};
        while (!st.empty()) {
            auto [u, head] = st.back();
            st.pop_back();
            for (int v = u; v != -1; v = heavy[v]) {
                top[v] = head;
                pos[v] = ++timer;
                for (int w : g[v])
                    if (par[w] == v && w != heavy[v])
                        st.push_back({w, w});
            }
        }
    }
    template <class F> void path(int u, int v, F visit) {
        while (top[u] != top[v]) {
            if (dep[top[u]] < dep[top[v]])
                swap(u, v);
            visit(pos[top[u]], pos[u]);
            u = par[top[u]];
        }
        if (dep[u] > dep[v])
            swap(u, v);
        visit(pos[u], pos[v]);
    }
};

实现要点pos 从 1 开始，子树区间是 [pos[u],pos[u]+sz[u]−1]。当前 path 仅适合加法、最大值

等不依赖方向的聚合；字符串拼接或矩阵乘法要保留方向。边权挂在较深端点，同链最后一段 排除 LCA。

8.4换根 DP 与树重心

正确性树上两点路径唯一，根跨过边 u−v 后每个点恰好落在这条边的一侧，距离变化只能是

加一或减一。重心的最大块不超过 n/2：若存在更大块，向它移动会减小最大块，直到无法继 续。 图 8.2 换根时两侧距离贡献的变化

vector<ll> all_distance_sum(const vector<vector<int>> &g) {
    int n = g.size();
    vector<int> par(n, -1), dep(n), sz(n, 1), order{0};
    par[0] = 0;
    for (int i = 0; i < n; ++i) {
        int u = order[i];
        for (int v : g[u])
            if (v != par[u]) {
                par[v] = u;
                dep[v] = dep[u] + 1;
                order.push_back(v);
            }
    }
    for (int i = n - 1; i; --i)
        sz[par[order[i]]] += sz[order[i]];
    vector<ll> ans(n);
    ans[0] = accumulate(dep.begin(), dep.end(), 0LL);
    for (int i = 1; i < n; ++i) {
        int v = order[i];
        ans[v] = ans[par[v]] + n - 2 * sz[v];
    }
    return ans;
}

8.5树结构与边界处理

二叉树的遍历、序列化、重建与搜索树判定都应先明确节点关系及空节点的表示。一般树 则通过孩子列表遍历。计算含空位的层宽时，应先规范化层内编号，避免编号随深度指数增 长。 树直径在非负边权下可两次最远搜索，直径端点能帮助计算每个节点的最远距离。无权树 的重心、中心与直径中点分别服务于分量控制与距离目标。树上背包合并孩子时应计入实际子 树大小，避免每个点都跑满容量造成不必要的开销。

9字符串匹配与回文结构

字符串查询先按对象分类：单模式匹配、前后缀关系、多模式统计、子串相等与回文分别 使用不同结构。把匹配进度表示为自动机状态后，还可与数位 DP、图搜索和计数模型组合。

9.1KMP 前缀函数与匹配

π[i] 是 s[0..i] 的最长真前后缀长度。失配时跳到 π[j−1]，因为任何仍可能匹配的更短前缀 必须是当前前缀的 border。每次增长与回退的总次数由 j 的变化量控制为线性。 图 9.1 沿前缀函数链枚举真前后缀

复杂度与接口前缀函数 O(m)，匹配 O(n+m)，空间 O(m)。

C++17
vector<int> prefix_function(const string &s) {
    vector<int> pi(s.size());
    for (int i = 1; i < (int)s.size(); i++) {
        int j = pi[i - 1];
        while (j && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            ++j;
        pi[i] = j;
    }
    return pi;
}
vector<int> kmp(const string &s, const string &p) {
    if (p.empty())
        return {};
    auto pi = prefix_function(p);
    vector<int> ans;
    int j = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        while (j && s[i] != p[j])
            j = pi[j - 1];
        if (s[i] == p[j])
            ++j;
        if (j == (int)p.size())
            ans.push_back(i - j + 1), j = pi[j - 1];
    }
    return ans;
}

实现要点空模式单独处理。模式匹配成功后回到 pi[m−1]，才能统计重叠匹配；树与链表匹

配的分叉情形不能直接照搬单串线性复杂度结论。 不断沿 π 链回退能枚举全部 border，周期长度候选为 n−π[n−1]。若要求整个串由某段重 复，还需 n 能被该长度整除；只有局部周期时不应加这个条件。 树的子结构匹配若通过序列化转为字符串匹配，必须保留空节点标记。删除重复子串或计 数不含某个禁串的字符串时，可把 KMP 的匹配前缀长度作为状态。

9.2Z 函数与前缀匹配

Z[i] 表示 s[i..] 与 s 的最长公共前缀长度。前缀函数适合描述真前后缀链，Z 函数适合描述 每个起点与全串前缀的匹配长度；二者都通过复用已知区间达到线性时间。 维护最右的匹配区间 [l,r]。i 在区间内时，可以复用 z[i−l]，但最多复用到 r；区间外从零 开始比较。只有越过已知右端点的比较才可能推进 r，因此成功扩展的总次数为线性。

正确性区间内的字符与前缀对应相等，镜像位置提供确定的匹配下界；超过 r 的部分尚未

知，必须实际比较。每次失败只增加常数工作，每次成功越界都使右端点向右移动。

复杂度与接口O(n) 时间、O(n) 空间，约定 z[0]=n。模式匹配可对 p+分隔符+t 求 Z，分隔符必须不在输入字

符集中。

C++17
vector<int> z_function(const string &s) {
    int n = s.size();
    vector<int> z(n);
    if (n)
        z[0] = n;
    for (int i = 1, l = 0, r = -1; i < n; ++i) {
        if (i <= r)
            z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]])
            ++z[i];
        if (i + z[i] - 1 > r)
            l = i, r = i + z[i] - 1;
    }
    return z;
}

9.3双模字符串哈希

多项式哈希把相同长度子串映射到可快速提取的指纹。比较前先统一位置归一化与长度。 双模降低碰撞风险，却仍不是确定性的字符串相等证明。

复杂度与接口构建 O(n)，子串比较 O(1)，二分 LCP O(log n)。

C++17
struct Hash {
    static constexpr ll P1 = 1000000007, P2 = 1000000009;
    ll B;
    vector<ll> h1, h2, p1, p2;
    Hash(const string &s, ll base)
        : B(base), h1(s.size() + 1), h2(s.size() + 1), p1(s.size() + 1, 1),
          p2(s.size() + 1, 1) {
        assert(1 < base && base < P1);
        for (int i = 0; i < (int)s.size(); i++) {
            int x = (unsigned char)s[i] + 1;
            h1[i + 1] = (h1[i] * B + x) % P1;
            h2[i + 1] = (h2[i] * B + x) % P2;
            p1[i + 1] = p1[i] * B % P1;
            p2[i + 1] = p2[i] * B % P2;
        }
    }
    pair<ll, ll> get(int l, int r) const {
        return {(h1[r] - h1[l] * p1[r - l] % P1 + P1) % P1,
                (h2[r] - h2[l] * p2[r - l] % P2 + P2) % P2};
    }
};

实现要点实际比赛建议随机基数并保护对抗数据。判断需要绝对正确时优先 KMP 或确定性

字符串结构；哈希匹配还必须检查长度。 面对对抗数据，可随机选择合法底数或在可疑结果上验证原串；要求严格确定性时优先 KMP、Z 或后缀工具。不要把浮点哈希或有符号溢出当作模运算。 重复字符串匹配可扩展足够次数后检查；等长单词串联可按单词长度分组维护词频窗口。 近似匹配允许至多 k 处差异时，可用哈希二分下一处差异并跳过，单个起点需要 O((k+1)log n) 次量级操作，不能忽略 k。

9.4字典树的词频与前缀频次

Trie 共享词前缀，每个节点代表一个前缀。终止计数回答完整单词频次，路径通过计数回 答前缀频次；两者不能互相替代。

复杂度与接口一次词操作 O(词长)，空间 O(总字符数×字母表大小)。

C++17
struct Trie {
    struct N {
        array<int, 26> ch{};
        int pass = 0, end = 0;
    };
    vector<N> t{N{}};
    void add(const string &s, int delta = 1) {
        int u = 0;
        t[u].pass += delta;
        for (char c : s) {
            int x = c - 'a';
            if (!t[u].ch[x]) {
                assert(delta > 0);
                t[u].ch[x] = t.size();
                t.emplace_back();
            }
            u = t[u].ch[x];
            t[u].pass += delta;
        }
        t[u].end += delta;
    }
    int walk(const string &s) const {
        int u = 0;
        for (char c : s) {
            u = t[u].ch[c - 'a'];
            if (!u)
                return -1;
        }
        return u;
    }
    int count(const string &s) const {
        int u = walk(s);
        return u < 0 ? 0 : t[u].end;
    }
    int prefix(const string &s) const {
        int u = walk(s);
        return u < 0 ? 0 : t[u].pass;
    }
    bool erase(const string &s) {
        if (!count(s))
            return false;
        add(s, -1);
        return true;
    }
};

实现要点删除前检查单词存在。编码数字序列必须保留分隔符和符号，否则 [1,23] 与 [12,3]

9.5AC 自动机与多模式统计

模式串总长度很大时，逐个 KMP 会反复扫描文本。AC 自动机把 Trie 上的前缀共享，再 用 fail 指针在匹配失败时跳到最长可用后缀。 BFS 构造 fail，同时补齐缺失转移。扫描文本时只在当前状态加一次访问计数；结束后按 BFS 逆序把计数累加给 fail 父亲。这样到达长模式的次数也计入作为其后缀的短模式，避免每 个字符沿 fail 链逐个计数。

正确性状态表示当前文本前缀的最长模式前缀后缀。一个模式出现，当且仅当当前状态的

fail 祖先链包含它的终止节点。逆序汇总正是对这条祖先关系做子树贡献合并。重复模式保存 相同终点，分别读取相同计数即可。

复杂度与接口字母表大小 σ 时建自动机 O(σL)，扫描与汇总 O(|S|+L)，空间 O(σL)。代码字符集为小写英文

字母，build 后不可继续插入。

C++17
struct Aho {
    struct Node {
        array<int, 26> go{};
        int fail = 0;
        ll cnt = 0;
    };
    vector<Node> t{Node{}};
    vector<int> order;
    int insert(const string &s) {
        int u = 0;
        for (char c : s) {
            int x = c - 'a';
            if (!t[u].go[x]) {
                t[u].go[x] = t.size();
                t.push_back(Node{});
            }
            u = t[u].go[x];
        }
        return u;
    }
    void build() {
        queue<int> q;
        for (int v : t[0].go)
            if (v)
                q.push(v);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            order.push_back(u);
            for (int x = 0; x < 26; ++x) {
                int v = t[u].go[x];
                if (v) {
                    t[v].fail = t[t[u].fail].go[x];
                    q.push(v);
                } else
                    t[u].go[x] = t[t[u].fail].go[x];
            }
        }
    }
    void count(const string &s) {
        for (auto &v : t)
            v.cnt = 0;
        int u = 0;
        for (char c : s) {
            u = t[u].go[c - 'a'];
            ++t[u].cnt;
        }
        for (int i = int(order.size()) - 1; i >= 0; --i) {
            int v = order[i];
            t[t[v].fail].cnt += t[v].cnt;
        }
    }
};

9.6二进制 Trie 与最大异或

最大异或从最高位决定胜负：在已固定更高位后，当前位尽量选与 x 相反的分支。如果该 分支存在任何候选，就一定优于同位分支，不需考虑更低位补偿。

复杂度与接口最大异或 O(nB)，空间 O(nB)，B 为二进制位数。

C++17
struct XorTrie {
    vector<array<int, 2>> t{{-1, -1}};
    void add(uint32_t x) {
        int u = 0;
        for (int b = 31; b >= 0; b--) {
            int v = x >> b & 1;
            if (t[u][v] < 0) {
                t[u][v] = t.size();
                t.push_back({-1, -1});
            }
            u = t[u][v];
        }
    }
    uint32_t best(uint32_t x) const {
        int u = 0;
        uint32_t ans = 0;
        for (int b = 31; b >= 0; b--) {
            int v = x >> b & 1;
            if (t[u][v ^ 1] >= 0)
                ans |= 1U << b, u = t[u][v ^ 1];
            else
                u = t[u][v];
            assert(u >= 0);
        }
        return ans;
    }
};

9.7Manacher 与全部回文半径

最长回文子串不能由最长回文子序列 DP 替代。子串要求连续，Manacher 利用左右对称， 把所有中心的扩展复用成线性计算。分别存奇、偶回文半径可以避免引入特殊分隔字符。 d1[i] 表示以 i 为中心的奇回文半径，长度为 2d1[i]−1；d2[i] 表示中心位于 i−1 和 i 之间的 偶回文半径，长度为 2d2[i]。维护最右回文区间，区间内部用对称中心的已知半径初始化，再 尝试越界扩展。

int longest_palindrome(const string &s) {
    int n = s.size(), ans = 0;
    vector<int> d1(n), d2(n);
    for (int i = 0, l = 0, r = -1; i < n; ++i) {
        int k = i > r ? 1 : min(d1[l + r - i], r - i + 1);
        while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
            ++k;
        d1[i] = k;
        ans = max(ans, 2 * k - 1);
        if (i + k - 1 > r)
            l = i - k + 1, r = i + k - 1;
    }
    for (int i = 0, l = 0, r = -1; i < n; ++i) {
        int k = i > r ? 0 : min(d2[l + r - i + 1], r - i + 1);
        while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
            ++k;
        d2[i] = k;
        ans = max(ans, 2 * k);
        if (i + k - 1 > r)
            l = i - k, r = i + k - 1;
    }
    return ans;
}

10.1模乘快速幂与矩阵快速幂

快速幂把指数按二进制拆分，每次平方一次底数。矩阵乘法同样满足结合律，所以用转移 矩阵把线性递推推到第 n 项。行向量或列向量只要从定义到乘法始终一致即可。

Mat multiply(const Mat &a, const Mat &b, ll mod) {
    int n = a.size();
    Mat c(n, vector<ll>(n));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            for (int j = 0; j < n; j++)
                c[i][j] = (c[i][j] + (i128)a[i][k] * b[k][j]) % mod;

    assert(e >= 0);
    int n = a.size();

    for (int i = 0; i < n; i++)
        r[i][i] = 1 % mod;

        a = multiply(a, a, mod);
        e >>= 1;

    return r;

        for (int i = 2; i <= n; ++i) {
            if (!composite[i]) {
                primes.push_back(i);
                phi[i] = i - 1;
                mu[i] = -1;
            }
            for (int p : primes) {
                if (p > n / i)
                    break;
                int x = i * p;
                composite[x] = 1;
                if (i % p == 0) {
                    phi[x] = phi[i] * p;
                    mu[x] = 0;
                    break;
                }
                phi[x] = phi[i] * (p - 1);
                mu[x] = -mu[i];
            }
        }
    }
};

实现要点μ 不是所有数论题都应使用的工具。先尝试按 gcd 分类、因数枚举和普通容斥；式

子中存在整除计数且需要筛掉非互质时，再考虑反演。

optional<pair<i128, i128>> crt(i128 a, i128 m, i128 b, i128 n) {
    assert(m > 0 && n > 0);
    a = norm(a, m);
    b = norm(b, n);

    if (d % g)
        return nullopt;

10.5组合数阶乘逆元与 Catalan

组合数阶乘逆元法利用 C(n,k)=n!/(k!(n−k)!)，除法在素数模数下用逆元替代。所有阶乘非 零要求 n<p。Catalan 的除以 n+1 同样需要逆元存在。

复杂度与接口预处理 O(N+log p)，查询 O(1)，空间 O(N)。

C++17
struct Comb {
    ll p;
    vector<ll> f, iv;
    Comb(int N, ll prime) : p(prime), f(N + 1, 1), iv(N + 1, 1) {
        assert(N < p); // prime 的素性由调用者保证。
        for (int i = 1; i <= N; i++)
            f[i] = (i128)f[i - 1] * i % p;
        iv[N] = modpow(f[N], p - 2, p);
        for (int i = N; i > 0; i--)
            iv[i - 1] = (i128)iv[i] * i % p;
    }
    ll C(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return (i128)f[n] * iv[k] % p * iv[n - k] % p;
    }
};
ll catalan_dp(int n, ll mod) {
    vector<ll> c(n + 1);
    c[0] = 1 % mod;

        for (int j = 0; j < i; j++)

10.6Lucas 定理与整除分块

阶乘逆元法要求预处理范围小于素数模数。n 很大而模数 p 是较小素数时，可以按 p 进制 逐位计算组合数。另一种常见压缩来自 ⌊n/i⌋：它只在 O(√n) 个区间上变化。 Lucas 公式为 C(n,k)≡∏C(n_i,k_i) mod p。每位小于 p，局部组合数用阶乘表即可。整除分 块中，从左端 l 出发，商 q= n/l ⌊ ⌋不变的最右位置是 r= n/q ⌊ ⌋；对区间求和后跳到 r+1。

正确性在模 p 下 (1+x)^p≡1+x^p，按 p 进制展开 (1+x)^n，各位系数相乘得到 Lucas。分块的

ll lucas(ll n, ll k, ll p, const vector<ll> &fac, const vector<ll> &ifac) {
    ll ans = 1;
    while (n || k) {
        ll a = n % p, b = k % p;
        if (b > a)
            return 0;
        ans = ans * fac[a] % p;
        ans = ans * ifac[b] % p * ifac[a - b] % p;
        n /= p;
        k /= p;
    }
    return ans;
}
i128 floor_sum_positive(ll n) {
    i128 ans = 0;

        r = n / q;

10.7容斥与二项式反演

容斥先计算容易统计的“至少满足某些条件”，按选择条件数交替加减，消除重复计数。 二项式反演把“至少 k 项”与“恰好 k 项”这两种计数关系互相转换。

C++17
ll divisible_union(ll N, const vector<ll> &primes) {
    int k = primes.size();
    assert(k < 25);
    ll ans = 0;
    for (int mask = 1; mask < (1 << k); mask++) {
        ll product = 1;
        bool ok = true;
        for (int i = 0; i < k; i++)
            if (mask >> i & 1) {
                if (product > N / primes[i]) {
                    ok = false;
                    break;
                }
                product *= primes[i];
            }
        if (ok)
            ans += (__builtin_popcount((unsigned)mask) & 1 ? 1 : -1) *
                   (N / product);
    }
    return ans;
}

例题10.1 The Chariot 超长整数与策略压缩

2024 CCPC 济南 E

问题出租车起步 A 元含 X 米，之后 Y 米按 B 元每米，其后按 C 元每米。随时可重新打车，

求 D 米最低成本。六个参数可长达约 2077 位。

解法先固定总共使用 k 辆车。每辆起步覆盖 X 米，总起步费 kA；若 D≤kX，已经足够。否则

还要付费跑 R=D−kX 米。 若 B≤C，应优先用完所有车辆较便宜的 B 区间，共 kY 米，因此费用为 kA+B·min(R,kY) +C·max(R−kY,0)。若 B>C，应把付费里程集中到同一辆车，最多经历一次 Y 米的 B 区间，再 用更便宜的 C；费用为 kA+B·min(R,Y)+C·max(R−Y,0)。 只需考虑 1≤k≤D/X ⌈ ⌉，更多车辆只会增加起步费。每一段内费用关于 k 都是一次函数，最 小值在该段的整数端点取得。B≤C 时分界在 D/(X+Y)、D/X；B>C 时分界在 (D−Y)/X、D/X。 收集 1、⌈D/X⌉，以及各非负分界的向下取整与再加一；过滤超出范围的 k，用上式计算 并取最小。这把命题组按 A、AB 与 C 计价段列出的有限策略，改写成统一的分段线性候选算 法。所有运算使用高精度整数。

正确性固定 k 时，免费里程总应尽量使用。B 不贵于 C 时，把付费里程分配到仍有 B 容量的

车不会变差；B 贵于 C 时，将多个付费尾段合到同一车能减少反复跨越 B 区间。所得费用在 各分界之间为一次函数，整数最优只能位于端点附近，有限候选完整覆盖。

米按 B 付 5，总费 25；三辆费用 30。最优为两辆。不能只比较 A/X、B、C 后决定一直使用某 个区间。

// 依赖本章的 cpp_int
cpp_int taxi_cost(cpp_int A, cpp_int B, cpp_int C, cpp_int D, cpp_int X,
                  cpp_int Y) {
    cpp_int limit = (D + X - 1) / X;
    vector<cpp_int> cand{1, limit};
    auto boundary = [&](cpp_int q) {
        cand.push_back(q);
        cand.push_back(q + 1);
    };
    boundary(D / X);
    if (B <= C)
        boundary(D / (X + Y));
    else if (D > Y)
        boundary((D - Y) / X);
    cpp_int best;
    bool found = false;
    for (cpp_int k : cand) {
        if (k < 1 || k > limit)
            continue;
        cpp_int r = D - k * X, value = k * A;
        if (r > 0) {
            cpp_int cap = Y;
            if (B <= C)
                cap = k * Y;
            cpp_int z = min(r, cap);
            value += z * B + (r - z) * C;
        }
        if (!found || value < best)
            best = value, found = true;
    }
    return best;
}

struct Basis {

11.2实数高斯消元

高斯消元把每列的主元变为一，再消去其他行对应列，从而读出变量。没有主元的列表示 自由变量；全零系数但非零常数的行表示无解。

复杂度与接口m 条方程、n 个未知数 O(mn²)，方阵为 O(n³)。

C++17
int gauss(vector<vector<double>> a, vector<double> &x) {
    const double EPS = 1e-9;
    int m = a.size(), n = a[0].size() - 1, row = 0;
    vector<int> where(n, -1);
    for (int c = 0; c < n && row < m; c++) {
        int sel = row;
        for (int i = row; i < m; i++)
            if (abs(a[i][c]) > abs(a[sel][c]))
                sel = i;
        if (abs(a[sel][c]) < EPS)
            continue;
        swap(a[sel], a[row]);
        where[c] = row;
        double t = a[row][c];
        for (int j = c; j <= n; j++)
            a[row][j] /= t;
        for (int i = 0; i < m; i++)
            if (i != row) {
                double k = a[i][c];
                for (int j = c; j <= n; j++)
                    a[i][j] -= k * a[row][j];
            }
        ++row;
    }
    for (int i = 0; i < m; i++) {
        bool zero = true;
        for (int j = 0; j < n; j++)
            zero &= abs(a[i][j]) < EPS;
        if (zero && abs(a[i][n]) >= EPS)
            return -1;
    }
    x.assign(n, 0);
    for (int j = 0; j < n; j++)
        if (where[j] >= 0)
            x[j] = a[where[j]][n];
    return row == n ? 1 : 0;
}

实现要点EPS 根据数据规模选择；接口返回 −1 无解、0 多解、1 唯一解。球心问题先将两点

等距方程相减，消去平方未知项。 实数版本选绝对值较大的主元降低误差，eps 不是精确零判断。无解、唯一解和无穷多解 要分别返回；不能把自由变量默认为零后声称唯一。 运算数域决定消元规则。实数消元需误差判定，素数模消元使用逆元，GF(2) 消元使用异 或；合数模中的非零主元可能不可逆。最少开关次数还需优化解空间，不能仅返回任意一组 解。

11.3GF2 高斯消元的位压缩版本

GF2 消元中加减都变成异或，可以用 bitset 同时消去整行。除主元归一化外，消元结构与 实数相同；主元本身只有 1，不需要求逆。

C++17
int gauss2(vector<bitset<513>> a, int n, vector<int> &x) {
    assert(n <= 512);
    int m = a.size(), r = 0;
    vector<int> w(n, -1);
    for (int c = 0; c < n && r < m; c++) {
        int s = r;
        while (s < m && !a[s][c])
            ++s;
        if (s == m)
            continue;
        swap(a[s], a[r]);
        w[c] = r;
        for (int i = 0; i < m; i++)
            if (i != r && a[i][c])
                a[i] ^= a[r];
        ++r;
    }
    for (int i = 0; i < m; i++) {
        bool zero = true;
        for (int c = 0; c < n; c++)
            zero &= !a[i][c];
        if (zero && a[i][n])
            return -1;
    }
    x.assign(n, 0);
    for (int c = 0; c < n; c++)
        if (w[c] >= 0)
            x[c] = a[w[c]][n];
    return r;

int gauss_mod(vector<vector<ll>> a, ll p, vector<ll> &x) {
    int m = a.size(), n = a[0].size() - 1, r = 0;
    vector<int> w(n, -1);
    for (auto &row : a)
        for (ll &v : row)
            v = (ll)(((i128)v % p + p) % p);
    for (int c = 0; c < n && r < m; c++) {
        int s = r;
        while (s < m && !a[s][c])
            ++s;
        if (s == m)
            continue;
        swap(a[s], a[r]);
        w[c] = r;
        ll iv = modpow(a[r][c], p - 2, p);
        for (int j = c; j <= n; j++)
            a[r][j] = (i128)a[r][j] * iv % p;
        for (int i = 0; i < m; i++)
            if (i != r) {
                ll k = a[i][c];
                for (int j = c; j <= n; j++)
                    a[i][j] =
                        (ll)(((i128)a[i][j] - (i128)k * a[r][j] % p + p) % p);
            }
        ++r;
    }
    for (int i = 0; i < m; i++) {
        bool zero = true;
        for (int c = 0; c < n; c++)
            zero &= a[i][c] == 0;
        if (zero && a[i][n])
            return -1;
    }
    x.assign(n, 0);
    for (int c = 0; c < n; c++)
        if (w[c] >= 0)
            x[c] = a[w[c]][n];
    return r == n ? 1 : 0;
}

11.6概率 DP 与期望方程

概率题先区分“状态出现的概率”和“从状态开始的期望代价”。前者常向后分配概率质 量，后者常从后继状态反推。只有独立事件才可以直接相乘，但期望的线性性不要求独立。 若从状态 i 一次付出代价 c_i，再以 p_ij 进入 j，则 E_i=c_i+Σp_ijE_j。状态无环时按逆拓 扑序求；有自环时把 p_iiE_i 移到左侧；有多状态循环时可能要解线性方程。若有策略选择， 对每个可行动作分别计算期望，再取最优。

正确性全期望公式按下一步的互斥完备结果分解。若目标状态以概率一到达且期望有限，方

vector<int> game_states(const vector<vector<int>> &g) {
    int n = g.size();
    vector<vector<int>> rev(n);
    vector<int> left(n), s(n, -1);
    queue<int> q;
    for (int u = 0; u < n; u++) {
        left[u] = g[u].size();
        for (int v : g[u])
            rev[v].push_back(u);
        if (!left[u])
            s[u] = 0, q.push(u);
    }
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : rev[v])
            if (s[u] < 0) {
                if (s[v] == 0)
                    s[u] = 1, q.push(u);
                else if (--left[u] == 0)
                    s[u] = 0, q.push(u);
            }
    }
    return s; // 0 败，1 胜，-1 和局。
}

无合法行动者败。 剩余未确定节点可能形成可无限循环的局面，通常按题目规则为和局。存在强制步数上 限、不同终止规则或非零和目标时，分类需要调整。

一组，之后只需常数规模检查。 对某个候选中心 O，检查其余点两两：cross(O,A,B)=0 且 dot(A−O,B−O)>0 才表示同一射 线，会有线段重叠。 逐一尝试五个候选中心即可。题目保证输入点互异；若推广到允许重复点的情形，需先去 重，再核对是否仍有至少五个点。 固定四点，若它们已经不全共线，任加第五点即可；否则扫描一个不在该直线上的点。

正确性关键五点存在性结论可分为无三点共线、四点共线、恰有三点共线三类；后两类都能

选线外点或中间点避免同射线。实现只需验证具体中心，证明与代码可以分开。

示例推演四点在 x 轴上，再加一点 (0,1)。以 (0,1) 为中心，向 x 轴上四个互异点的线段只在

中心相交。若选 x 轴端点为中心，其他轴上点可能在同射线。

实现要点共线不等于重叠：中心两侧的反向射线合法。坐标差乘法使用 i128；不要用浮点角

度比较同射线。

复杂度O(n) 找五点，O(1) 验证，额外空间 O(1)。

练习建议用整数坐标生成无共线、三点共线、四点共线、全共线数据。画出反向射线作为必

测反例。

例题12.2 What More Kangaroos 极角覆盖与远点缩放

问题若干袋鼠的同步操作可转为不等式 a[i]x+b[i]y+c[i]<0，其中 c[i]>0，找整点使满足的不等

式尽量多。

解法固定一个非零方向 (x,y)，沿该方向放大 t。若 a[i]x+b[i]y<0，则充分远处可以抵消正

c[i]；反之永远不满足。 因此 c[i] 只影响需要走多远，不影响方向是否最终可行。问题变为最大数量法向量与目标 方向点积严格为负。 每个不等式对应圆周上的一个开半圆，极角排序并将序列复制一次，用双指针找严格半圆 内最多法向量。 同方向与反方向要精确分组。用象限、叉积比较角度，端点严格性用点积及叉积判断，不 使用粗糙 EPS。

正确性方向放大不改变齐次部分符号。所有可行方向组成有限个开区间，而有理斜率在开区

间中稠密，可取整数方向，充分放大后同时满足其对应的不等式。

示例推演x+2y+3<0 与 −x+y+5<0。方向 (−1,−1) 的齐次项分别为 −3 与 0，放大只能满足第一

条；方向 (−1,−2) 分别为 −5 与 −1，足够大时两条都满足。

实现要点齐次项等于 0 时 c>0，严格不等式必定不成立。a=b=0 的式子直接忽略。角度窗口

跨过 2π 必须复制或循环处理。

复杂度O(n log n) 时间，O(n) 空间。
