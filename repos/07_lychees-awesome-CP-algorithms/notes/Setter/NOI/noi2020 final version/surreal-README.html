surreal验题反馈

  • surreal.cpp是我写的 $O(mn)$ 暴力做法，surreal(random).cpp是随机做法，val.cpp是数据校验器。
  • 数据强度出现了比较严重的问题，暴力实现的surreal.cpp可以很轻松得到100分。这个实现是基于在一棵Trie树上dfs，维护另一棵Trie树上已经被覆盖的叶子集合。用数组直接暴力维护线段树区间加、求极值就可以得到100分。
