一些可能的部分分做法

$1 \le n,m \le 10^2$ 的部分分：每次询问枚举两个点，$O( n^2m )$ 暴力。

$1 \le n,m \le 5 \times 10^3$ 的部分分：发现这个问题实际上是求一个子集的逆序对数，每次询问找出这个子集中所有点，用排序后树状数组的方法或者归并排序的方法求逆序对，$O( nm\log n)$。

对于所有的询问，满足 $y=1$ 且 $y'=n$ 的部分分：发现这个问题实际上等价于一个序列的区间逆序对问题，可以使用莫队算法+树状数组来 $O( n\sqrt m\log n)$ 解决，这个复杂度可能只能通过部分数据，也可以使用二次离线的莫队算法来 $O( n\sqrt m)$ 解决，这个复杂度可以通过所有部分分。

对任意两次不同的询问 $x_i,x_i',y_i,y_i'$ 与 $x_j,x_j',y_j,y_j'$，要么 $(x_i,y_i) \le (x_j,y_j) \le (x_j',y_j') \le (x_i',y_i')$，要么 $(x_j,y_j) \le (x_i,y_i) \le (x_i',y_i') \le (x_j',y_j')$，要么不存在整数 $a,b \in [1,n]$ 使得 $(x_i,y_i) \le (a,b) \le (x_i',y_i')$ 且 $(x_j,y_j) \le (a,b) \le (x_j',y_j')$ 的部分分：发现询问的矩形要么互相包含，要么互相不相交，这个是满足树形结构的性质的，可以扫描线建树，将询问建成一个森林的形式，然后在这个询问的森林上启发式合并可以得到所有询问的答案。如果启发式合并+树套树维护，会得到一个 $O(m\log^3 n)$ 的做法，这个复杂度可能只能通过部分数据.如果启发式合并，用可持久化值域线段树预处理，可以做到 $O(m\log^2 n)$，这个复杂度可以通过所有部分分。

第 $i$ 组数据满足 $n=i \times 10^4$，$m=i \times 2 \times 10^4$，这是一个有梯度的部分分，可以使用一些复杂度较高的算法获得部分分数，比如使用一个平面的莫队算法（被称作”二维莫队“），这样总的转移量是 $O( nm^{3/4} )$ 的，如果使用数据结构，如树状数组来维护，可能只能获得有限的部分分，可以使用一种先将莫队的转移顺序求出来，之后再进行一次离线扫描线的方法将复杂度优化到 $O( nm^{3/4} )$，视算法的优秀程度可以获得可观的部分分。

解题报告

简要题意：给出平面上的n个点，m次询问，每次询问给出一个矩形，问矩形内的支配对个数。不失一般性可以设点的x,y坐标构成$1$到$n$的排列，$n=2^k$，询问满足$(1,1)\le (x,y)\le (x',y')\le (n,n)$。 定义x-半正则矩形为形如$(X_1,X_2]\times(2^{k_2}Y,2^{k_2}(Y+1)]$ 的平面区域，其中$k_1,k_2,X_1,X_2,Y$为非负整数，且$X_1\le X_2\le n,\;2^{k_2}(Y+1)\le n$。对称地，可以定义y-半正则矩形。 定义正则矩形$R(X,Y,k_1,k_2)$为平面区域 $(2^{k_1}X,2^{k_1}(X+1)]\times(2^{k_2}Y,2^{k_2}(Y+1)]$； 其中$k_1,k_2,X,Y$为非负整数，且$2^{k_1}(X+1)\le n,\;2^{k_2}(Y+1)\le n$。 构建有向无环图$G$，顶点集为所有正则矩形，边集构造如下： $R(X,Y,k_1,k_2)\to R(2X+0,Y,k_1-1,k_2)$； $R(X,Y,k_1,k_2)\to R(2X+1,Y,k_1-1,k_2)$； $R(X,Y,k_1,k_2)\to R(X,2Y+0,k_1,k_2-1)$； $R(X,Y,k_1,k_2)\to R(X,2Y+1,k_1,k_2-1)$。 $G$的顶点有$\Theta(n^2)$个，但在忽略 不包含给出的n个点中任意一个 的正则矩形时，只有$O(n\log^2 n)$个顶点需要考虑。通过容斥原理可以在$O(n\log^2 n)$时间内算出每个正则矩形内的点数和支配对个数。 对于一个询问，需要查询矩形$(x-1,x']\times(y-1,y']$中的支配对个数。这个矩形可以被分成$O(\log n)$个x-半正则矩形，或$O(\log n)$个y-半正则矩形，或$O(\log^2 n)$个正则矩形（即一个x-半正则矩形和一个y-半正则矩形的交）。已知这些矩形内的点数和支配对个数，可以在$O(\log^2 n)$时间内通过容斥算出答案。 x-半正则矩形中的支配对个数在以上讨论中还未计算。考虑每个形如$(2^{k_2}Y,2^{k_2}(Y+1)]$的y区间内的点，以及对应的x-半正则矩形查询，问题转化为经典计数问题 区间逆序数，在点数$n_1$询问数$m_1$时使用 莫队算法 可以在$O(m_1+n_1\sqrt m_1)$时间内解决。存在理论复杂度更低的做法，但由于依赖于快速矩阵乘法而不实用。y-半正则矩形同理可以处理。这部分可以视为分治进行分析，可以发现询问的不均并不会导致总复杂度变差，时间复杂度： $T(n)=\sum\limits_{i=0}^{k}T'(n,2^k,2m)$ $T'(n,d,m)=\max\limits_{\sum m_i=m}\sum\limits_{i=1}^d\frac n d \sqrt{m_i}$ 解得$T(n)=O\left(m\log n+n\sqrt m\right)$。 总的时间复杂度为$O\left(m\log n+n\sqrt m+n\log^2 n\right)$，空间复杂度和具体实现有关，一般的实现需要$O(n+m)$或$O\left((n+m)\log n\right)$空间。
